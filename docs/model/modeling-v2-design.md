## 1. 总体架构

```text
源系统（业务库）
    ↓ 源表字段映射
ODS 层（贴源）
    ├── ODS 维表源 → 从 ODS 建维表 → DIM 层
    └── ODS 主表/明细表 → 按业务过程派生 → DWD 层
                                              ↓
                                    DWD + DIM
                                              ↓ 从指标聚合
                                            DWS 层
                                              ↓ 从指标 + DWS 反推
                                            ADS 层
                                              ↓
                                          报表/大屏/API
```

## 2. 五层建模方式

| 层 | 建模方式 | 输入 | 输出 |
| --- | --- | --- | --- |
| ODS | 源表字段映射 | 源表 | ODS 模型 |
| DIM | 从 ODS 建维表 | ODS 表 | DIM 维表 |
| DWD | 按业务过程派生 | 业务过程 + ODS 主表/明细表 | DWD 事实表（默认宽表） |
| DWS | 从指标聚合 | 指标 + DWD + DIM | DWS 汇总表 |
| ADS | 从指标 + DWS 反推 | 指标 + DWS（或 DWD） | ADS 应用表 |
| 兜底 | 手工建模 | 用户自定义 / 导入已有模型字段 | 任意 |

## 3. 各层详细设计

### 3.1 ODS 层（源表字段映射）

流程：选数据源 → 选库/schema → 选表 → 系统读取字段 → 表名加 `ods_` 前缀 → 补充技术字段（`system_time`/`event_time`）→ 类型兼容映射 → 标准关联（字段名匹配标准字段库，类型标准按关键词匹配）→ 字段匹配校验。

治理边界：ODS 轻治理（表名、技术字段、类型兼容、标准关联、字段匹配校验），不做码值/单位/口径/安全治理。

### 3.2 DIM 层（从 ODS 建维表）

流程：选 ODS 表（如 `ods_crm_customer`）→ 确认维表字段（选需要的字段）→ 确认主键（维度唯一标识）→ 保存。

关键：维表来自 ODS；主键是维度唯一标识；支持 SCD Type 2（历史维表）。实现依托 49/50（从 ODS 派生 + 代理键/SCD 约定列）。

### 3.3 DWD 层（按业务过程派生）

流程：选业务过程（如「下单」）→ 系统带出 ODS 主表/明细表与字段列表 → **默认宽表**（join DIM 维表、维度退化）→ 可选排除维表（纯事实表）→ 治理（命名/类型/码值/单位/口径/安全）→ 保存。

关键决策：
- **D3 默认宽表**：DWD 默认 join DIM 维表并做维度退化；可选排除维表成纯事实表；
- SCD 维度不建议退化（保留历史维表引用）。

DWD 两种形态：

| 形态 | 是否 join 维表 | 适用 |
| --- | --- | --- |
| 宽表（默认） | ✅ join | 分析常用 |
| 纯事实表 | ❌ 不 join | 保留明细 |

### 3.4 DWS 层（从指标聚合）

流程：选指标（如 GMV、订单量）→ 系统反推（分析指标依赖的口径/维度 → 分析 DWD 来源 → 分析 DIM 来源 → 生成 DWS 表结构草稿）→ 确认字段（维度：order_date、order_city；度量：sum_order_amount、order_cnt；用户可调）→ 保存。

关键：**D7 指标在前**（指标中心先行定义），DWS 按指标算，从 DWD 聚合、join DIM。

### 3.5 ADS 层（从指标 + DWS 反推）

流程：选指标 → 选数据来源（○ 从 DWS（汇总报表，默认）／○ 从 DWD（明细/实时报表））→ 系统生成 ADS 表结构 → 用户调整 → 保存。

关键：**D6 从 DWD 取数是正常场景**（明细报表、实时报表、特殊口径），不是兜底。

### 3.6 手工建模（兜底）

适用：维表、临时表、工具表、特殊表。

方式：自定义字段（从零建）；**D8 导入已有模型字段**（选模型 → 选字段（多选）→ 导入后编辑）。

## 4. 建模方式按分层推荐（D9）

| 选的分层 | 推荐建模方式 | 输入 |
| --- | --- | --- |
| ODS | 源表字段映射 | 源表 |
| DIM | 从 ODS 建维表 | ODS 表 |
| DWD | 按业务过程派生 | 业务过程 + ODS 主表/明细表 |
| DWS | 从指标聚合 | 指标 + DWD + DIM |
| ADS | 从指标 + DWS 反推 | 指标 + DWS（或 DWD） |
| 兜底 | 手工建模 | 用户自定义 |

用户选了分层，系统默认对应方式，用户可改。

## 5. 统一入口（D10）

```
新建模型（抽屉）
├── 一、通用信息
│     ├── 模型名称 *
│     ├── 模型编码 *（手填）
│     ├── 目标分层 *
│     │     └── ⓘ 目标库/数据源/方言（tooltip）
│     ├── 业务域 *（树形选择器）
│     ├── 业务过程（可选，选了自动带出业务域）
│     └── 描述（可选）
├── 二、建模方式（按分层推荐）
│     ├── ○ 源表字段映射（ODS）
│     ├── ○ 从 ODS 建维表（DIM）
│     ├── ○ 按业务过程派生（DWD）
│     ├── ○ 从指标聚合（DWS）
│     ├── ○ 从指标 + DWS 反推（ADS）
│     └── ○ 手工建模（兜底）
├── 三、方式特有信息（动态显示）
└── [下一步] → 字段页
```

## 6. 指标和 DWS 的关系（D7）

```text
① 指标定义（指标中心）
   ├── 原子指标：GMV = SUM(order_amount)
   ├── 原子指标：订单量 = COUNT(DISTINCT order_id)
   └── 复合指标：转化率 = 订单量 / UV
        ↓
② DWS 建模（从指标聚合）
   ├── 选指标
   ├── 系统反推 DWD + DIM 来源
   └── 生成 DWS 表结构
        ↓
③ DWS 物理表
   └── dws_trade_order_summary
        ↓
④ 指标引用 DWS
   └── GMV → dws_trade_order_summary.sum_order_amount
```

## 7. 完整数据流向

```text
源表 → ODS →（从 ODS 建维表）DIM
             └→（按业务过程派生）DWD（默认宽表 join DIM）→ DWD + DIM →（从指标聚合）DWS →（从指标 + DWS 反推）ADS → 报表/大屏/API
```

## 8. 闭环

指标定义（指标中心）→ DWS 建模（按指标算）→ DWS 物理表 → 指标引用 DWS → ADS 建模（从指标 + DWS）→ 报表/大屏/API → 反哺指标。

## 11. 一句话总结

**五层建模**：ODS 源表字段映射、DIM 从 ODS 建维表、DWD 按业务过程派生（默认宽表可排除维表）、DWS 从指标聚合、ADS 从指标 + DWS 反推（可 DWD 取数）、手工建模兜底（可导入字段）。

**关键**：指标在前、DWS 后建；DWD 默认宽表；ADS 支持 DWS/DWD 双源；建模方式按分层推荐；统一入口。
