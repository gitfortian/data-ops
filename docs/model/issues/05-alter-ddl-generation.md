**What to build:** DDL 六方言生成器（`645b5705e`）全部达到"可渲染完整 CREATE TABLE"级，但**只覆盖 CREATE**：已建表后的演进（加列/改类型/加索引）全靠人工比对手写。新增"变更脚本"能力：以最新已发布版本快照为基线、当前草稿结构为现状做结构 diff，按模型方言渲染 ALTER 语句集（复用 `AbstractDdlGenerator` 引号/转义件与 `DdlTypeResolver` 类型换算），DDL 弹窗增"建表/变更"两态；仍**仅生成不执行**（D3 不破）。

**模块归属:** modeling（ddl 包 + 版本包 + 前端 DDL 弹窗）

**Blocked by:** 10（版本快照明细完整度——快照若不含索引/分区，diff 基线不完整；先做 10 的确认再定 diff 范围）

**Status:** backlog(待排期)

**硬性约束(不可打破):** 遵守 [dev-plan.md《硬性开发约束》](../dev-plan.md)；六方言每方独立渲染路径 + 独立单测（对齐现有 DDL 测试布局）；不可回退的变更类型（改列序、CH 引擎差异）以注释提示交人，不编造默认；无已发布版本时回落 CREATE 全量脚本。
