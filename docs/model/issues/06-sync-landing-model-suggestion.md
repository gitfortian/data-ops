# 06: 同步落地表→建模建议联动

**对应需求:** 模型工作台盘点 §6 缺失能力（P2）| 阶段: P2

**What to build:** 04 图边"SYN/RTS --落地表--> MOD"目前**部分成立**：`data-ops-business-sync` 对 modeling 零引用，落地表纳入台账全靠人工发起逆向导入。补订阅式衔接：离线/实时同步任务发布或首跑成功后，对落地的目标表若尚无模型登记，生成"建议建模"待办清单（去重、可忽略），一键跳转逆向导入抽屉并预选该表。不自动建模型。

**模块归属:** **跨模块**——sync（offline + realtime，发事件） + modeling（建议清单 + 导入预选）；事件通道按项目既有 SPI/事件机制，禁止 sync 直接依赖 modeling 实现类

**Blocked by:** 无；开工前做裁决（事件总线 or 轮询扫描），结论落 04 主脉图文档

**Status:** backlog(待排期)

**硬性约束(不可打破):** 遵守 [dev-plan.md《硬性开发约束》](../dev-plan.md)；跨模块只经 `api` 包 SPI（04 图三分叉纪律）；建议清单纯提示性，不阻断任何同步执行链路；联动失败 fail-open。
