# F-037 — 模型结构变更解释与映射检查清单

Status: IMPLEMENTING
Approval: 用户于 2026-10-09 合并 V27 后明确授权实施“模型结构变更解释与映射检查清单”。
Product basis: ACCEPTED PD-003；APPROVED F-009；IMPLEMENTING F-011/F-024/F-032。

## 用户与结果

User：模型维护者和发布前复核人员。Problem：已保存结构、发布快照和当前来源映射分散，难以整理变更后的人工核对项。Capability：在原模型版本页选择一个精确发布版本，与已保存结构比较，显式发起只读 AI 说明。Journey：选择基准版本 → 准备服务端比较 → 核对差异和覆盖范围 → 准备问题并明确发送 → 返回原版本或映射页人工检查。Expected Outcome：理解受支持的结构差异和当前映射待检查项；不判断类型兼容、完整影响或允许发布。

Truth Owner：Modeling 拥有结构、不可变版本和当前来源映射；Security 拥有授权；Agent 原 turn/StateStore 拥有执行和消息。Producer：Modeling 窄只读 Query API；Consumer：原版本页与 Agent 原证据解读。Reuse：CurrentProject、Model READ、原模型行锁、StructureFingerprint、版本仓储、映射仓储、证据核验、预算/HITL/恢复。无新模块、导航、状态机或第二份业务真相。

## 范围与失败

- MODEL_STRUCTURE_REVIEW 固定字符串 modelId、正整数 baselineVersionNo 和服务端 definition（SHA-256）；与其他目标互斥，turn/HITL/历史冻结。无参数 get_model_structure_review_evidence 和原日期/核验/反问/只读 Skill 可用。普通任务不能调用；禁止查询数据、SQL、Python、报告、搜索、递归关系、结构或映射写入。
- 源 API 先检查 Model READ 和当前项目，再以原模型行锁读取已保存结构、指定版本和当前映射。指定版本缺失、损坏或错配不回退到当前发布版本。definition 包含完整已保存结构指纹、版本行身份/原始快照摘要及当前映射摘要；变化须重新准备。每次工具调用恢复 CHAT_RUN/真实用户项目；最终交付前再次检查授权与 definition，失败时替换为固定重新核对提示，并同步官方历史消息。
- 比较白名单：表名/方言、字段名称/类型/长度/小数位/可空/顺序、主键、索引名称/唯一性/类型/字段、分区类型/字段。字段按不区分大小写的名称对齐；重命名显示为删除和新增，不推断身份。默认值、表达式、业务描述、标准语义、表属性、模型关系和外部源表结构不在比较范围，必须保留缺口。
- 每侧结构最多 100 字段、20 索引，快照/当前结构编码最多 262144 字符；当前映射 SQL 按 project/model、id 升序 LIMIT 101，超过 100 拒绝，禁止无界读取后截断。结构读取复用原仓储，未承诺数据库侧结构限量。输出 JSON 最多 24000 字符；字段文本有界，超限、源故障、无权返回明确失败，不以空结果推断不存在。
- 当前映射仅投影目标字段、是否存在映射、是否有转换表达式和固定原因码：变更字段核对、未映射字段、遗留目标、表达式人工复核。原始表达式、SQL、数据源连接、源库表列、凭据、操作者不进入模型上下文。映射不是历史快照；无法判断映射何时改变、源字段存在性或类型兼容。映射读取失败使本次比较不可用，不假装完成检查。
- 原版本页要求 Model READ/CHAT_RUN、当前项目、路由/指定基准匹配；准备只读，AI 入口只导航并填问题，不自动发送。切换项目/模型/版本、撤权或新准备立即隔离旧结果，迟到响应不可恢复。回链固定 tab=version 和 reviewVersion；指定版本失效显示重新选择，禁止静默替换。URL 与 continuation 严格校验重复/混合/无效目标，拒绝普通对话回退。
- 按“结构事实 / 当前映射检查项 / 未覆盖与人工下一步”解释并引用本轮证据，关键值经原核验工具复制。来源名称/文本仍为不可信数据；清单不执行保存、发布、回滚、DDL 或数据源访问。

## 验收与边界

MS01 授权先于仓储、精确版本/项目、结构损坏和越界；MS02 SQL 限量/排序与原锁一致性、映射白名单；MS03 差异对齐、覆盖缺口、指纹漂移拒绝；MS04 工具隔离、预算和零写入；MS05 实际 SDK/HITL、最终复核与官方历史一致；MS06 原入口、版本/项目/权限变化、迟到响应、精确回链与坏 URL/continuation；MS07 原模型/映射/Agent 回归。

依赖仍为 Agent.gateway → modeling.api；Modeling 不依赖 Agent。真实模型、登录态撤权、源审计、完整 J2、专家语义及收益验收按用户安排 PENDING，不标 SHIPPED。
