## 用户、问题、能力与结果

质量治理人员和资产维护人员需要将授权证据转换成可核对的规则与描述，减少手工配置时间。提供来源与时点可见的回答、现有模板支持的规则候选和台账描述候选。用户审核后带入专业页面，在原权限、校验、并发保护和审计下明确保存；质量运行仍为单独动作。

## 用户旅程与事实归属

现有监控编辑器/资产快照编辑 → 输入业务约束 → 现有 Agent 轮次与只读源证据 → 候选校验/澄清 → 查看依据与缺口 → 带入未保存表单 → 人工保存 → 原页面回读；质量有运行权限时再显式运行。

Quality 拥有模板、注册物理目标、当前 Monitor/Rules/Settings、不可变执行计划及结果；Asset 拥有台账描述；Metadata/Datasource 拥有技术事实；Security 拥有授权。源域公开授权 API 为 producer，Agent 与编辑器为 consumer。候选与证据是生成材料，不成为第二份业务真相。

## 范围与复用

- 保留 AgentScope Java 2.0.2、StateStore、SSE、HITL、取消与身份/Project 守卫；证据显示来源、状态、读取时间和源更新时间。
- 质量建议针对当前已注册物理表和现有监控；最多 5 条。允许内置行数、非空、唯一、范围、枚举模板；参数缺业务依据时请求确认；不生成自定义 SQL。
- 新规则带入固定 disabled，不修改现有目标/Owner/过滤/调度/通知/失败策略，不自动保存或运行。人工保存说明启用监控可能影响后续自动运行及任务版本。
- 描述只带入 Asset description，最大 1024 字，不改源域注释、Owner、名称和访问入口；来源消失不能声称已掌握源事实。
- Quality 与 Asset 拥有条件更新，读取服务器定义指纹，事务内比较后写入；旧定义拒绝覆盖。兼容既有普通调用，新建议采纳页面强制使用前置条件。
- 复用源域原 Policy/Manager/审计；候选校验不触发调度、Task 发布或 Execution。显式治理目标轮次不写入/召回长期记忆；普通分析轮次一旦读取治理工具，也不提取治理内容为长期记忆。

## 非目标与安全

不新增一级导航、Maven module、业务状态机、审批流或长期建议库。Agent 不提供业务写工具、SQL/Python执行或自动修复；不扩大敏感分类/发布门禁/消费身份契约。自由文本语义支持需专家评测，引用存在不等于完全正确。

## 验收、指标与收口

自动化覆盖真实身份线程、公开 API 权限、非法模板/字段/阈值、字段漂移、原子旧值冲突、HITL/取消、候选只带入未保存表单、重复/切目标、消息历史一致和保存副作用。
