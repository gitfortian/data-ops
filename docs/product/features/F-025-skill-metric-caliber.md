# F-025 — 指标版本口径解释与业务说明 Skill

Status: IMPLEMENTING
Approval: 用户要求按 AgentScope 复用调研的推荐顺序与交付标准逐个完成，授权标准、模型映射后的指标场景复用。
Product basis: ACCEPTED PD-003，APPROVED F-005，IMPLEMENTING F-023/F-024。

User：指标设计者与审核人员。Problem：理解已保存公式、限定条件和引用版本并整理业务说明反复耗时。Capability：对当前已保存草稿的具体版本解释口径并生成业务说明草稿。Journey：打开原指标编辑框 → 核对已保存版本 → 加载 `metric-caliber-explanation` → 查看 AI 解读与原始事实 → 再校验带入 businessDesc → 人工保存 → 原列表回读。Expected Outcome：减少说明准备与核对耗时；真实收益尚待试点。

Truth Owner：Metric 拥有定义、不可变 MetricVersion、校验和发布真相；Skill 管理拥有方法版本；Agent turn/SDK StateStore 拥有轮次及消息。Producer：Metric 授权版本投影、原 SDK。Consumer：Agent gateway 与原指标编辑器。复用原项目/RBAC、版本快照 digest、Metric 乐观锁保存、审计与回读，以及 F-023/F-024 的 scoped Skill、结构化交付、预算、停止及历史一致保障。没有第二份定义库、新模块、一级导航或状态机。

## 场景合同

- 固定 metricId、已保存的当前版本与最多 512 字业务问题。仅当前草稿版本；历史快照和已发布版本不在本场景切换。每次准备、交付、采纳前先校验 Metric READ 与项目范围，再核验当前版本和不可变快照 digest。缺快照、畸形快照或源读取失败明确不可用。
- 只投影快照白名单中的名称、类型、公式、限定条件、维度、周期、单位 ID、模型/标准/指标引用及版本、业务说明。不得用可变子指标或标准现值冒充快照事实。ID 不是被引用对象的业务含义；版本 0 表示未记录。不上报负责人、连接配置、数据行、校验或发布状态。最多 65536 字符快照、每项 4096 字及总计 16000 字事实；超界失败，不能截断公式后继续解释。
- 必须加载启用的固定 Skill。SDK 输出至多一项业务说明草稿（512 字）、1–5 项解释（每项 512 字、1–4 个事实 key）及至多三项待确认问题（512 字）。引用只能来自本轮实际事实，标签和值由源域重新装配。引用与版本校验不证明自然语言语义正确，页面明示 AI 解读、展示原始事实并要求人工核对；不宣称校验/发布通过，不执行 SQL。
- 原编辑框成功读取完整详情，且口径表单未改动时才允许生成/采纳；表单、项目、对象、版本、权限变化及晚响应隔离。带入仅改 businessDesc，不保存，不改计算公式或引用；用户手工保存沿用原 expectedVersion、定义校验、审计、版本快照和回读。计算验证和发布仍由原流程显式触发。
- 本版首个指标草稿仅业务说明；完整指标定义生成是后续独立合同，不以当前解释能力冒充完成。

## 验收

自动化覆盖授权前零读取、快照有界和白名单、当前版本/快照漂移、未知事实引用和畸形/超量输出、Skill 加载/预算/结构化历史、表单采纳仅改说明与原 expectedVersion 保存、切换项目/表单及晚响应隔离。真实 E2E 需登录试点：原子/派生/复合指标分别解释并核对引用、带入、人工保存和回读，另测撤权、并发保存及停止；沿用户确认记录 PENDING，未完成不能 SHIPPED。
