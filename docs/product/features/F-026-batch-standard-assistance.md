# F-026 — 模型字段批量标准辅助

Status: IMPLEMENTING
Approval: 用户于 2026-10-08 授权新建分支开发下一批任务并提交 PR，明确将标准到指标再到消费的完整任务串联纳入本批。
Product basis: ACCEPTED PD-003；APPROVED F-005；IMPLEMENTING F-023。

User：建模人员。Problem：单字段逐次查找类型标准、整理字段说明耗时。Capability：原模型结构编辑器选择 1–5 个字段，逐项生成类型标准与字段业务说明候选。Journey：选择字段 → 显式开始批次 → 每字段独立原 Agent 轮次 → 核对当前值、候选、版本、依据及问题 → 逐项实时核验带入 → 原条件保存 → 回读。Expected Outcome：减少重复准备操作；真实耗时、返工与语义质量待试点。

Truth Owner：Semantic 拥有标准；Modeling 拥有字段/结构；原 turn 与 SDK StateStore 拥有轮次/消息；Skill 仓储拥有方法版本。Producer / Consumer：既有授权只读 API、轮次读模型生产证据，原模型编辑器消费候选；人工原保存生效。复用 F-023 的 SDK 结构化交付、Skill 快照、预算、原权限/Project、停止与条件保存。

批次仅为页面内存选择和顺序调用，不持久化批次、不成为业务状态机。每项独立会话、最多三项 TYPE 候选与一项至多 512 字的可选字段说明；字段说明是 AI 草稿而非标准定义。允许无匹配/信息不足；原单字段产出兼容缺失说明。每项最多一次自动提交；提交不确定或状态未确认时停止后续项，保留原会话链接供核对。停止/卸载阻止后续提交，并精确取消已确认的活动 turn；无 ID 不猜取消对象。

逐项带入前重查 Skill、源域授权、定义与标准版本；只改该选定字段的类型引用和用户明确选择的说明。未选字段、字段物理类型及其它标准引用不变。任何字段草稿变化使该项失效；项目/模型/定义切换使整批失效。人工带入不自动保存或发布。原 If-Match 保存冲突拒绝覆盖。

Domain Gap：F-023 只有单字段交互及类型候选，新增有界客户端顺序处理与可选说明合同；不新增源域 API、依赖走廊或 SDK 执行器。API 故障不得当空匹配；模型文本不作为保存输入。

验收 BS01–BS08：选择上限/未选保护、部分无匹配、坏输出、停止/提交晚回执、项目切换、草稿变化、采纳撤权/标准漂移、原条件保存与回读。自动化验证协议/隔离与副作用；真实模型登录态完整任务、审计、人工改动、版本/hash/trace、耗时单独 PENDING，不能标 SHIPPED。
