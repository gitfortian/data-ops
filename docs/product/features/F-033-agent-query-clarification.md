# F-033 — 问数字段、时间与口径澄清

Status: IMPLEMENTING
Approval: 用户于 2026-10-08 在后续规划中确认优先“问数字段、时间与口径澄清”，并要求继续实施。
Product basis: ACCEPTED PD-002/PD-003；IMPLEMENTING F-009/F-011/F-014/F-019。

## 用户、问题、能力与旅程

User：使用现有 Agent 查询 Dataset 的分析人员。Problem：字段同名、多个时间字段、金额/数量和去重规则不明确时，现有泛化反问缺少可核对依据，用户难以准确补充。Capability：在原反问中区分字段、时间、统计口径，展示本次授权发现的数据集版本和所选真实字段，支持选择或自由回答。Journey：提出问题 → 发现可读 Dataset/字段 → 有关键歧义时同轮反问 → 用户明确回答 → 重新发现版本/字段 → 原授权结构化查询 → 原查询证据与回答。Expected Outcome：用户知道为什么需要补充、在何种字段范围内回答；减少猜测，真实收益待试点。

Truth Owner：Dataset 拥有字段/版本及查询事实，Security 拥有权限；原 turn/官方 StateStore 拥有生命周期、pending 和应答。Producer：已有授权字段发现、原 SDK HITL 与受控反问投影；Consumer：原 Agent 页面、原恢复路径及继续推理。Reuse：get_dataset_fields、request_clarification、查询白名单/版本核对、预算、归属/项目、精确停止和原续跑。无新导航、模块、表、权限、业务状态或第二份真相。

## 本批范围

- 普通对话的原 request_clarification 增加可选 kind（FIELD/TIME/CALIBER）、dataset_id 和 field_ids。无 kind 的旧反问保持问题/选项协议；新类别属于该工具的展示协议，不新增任务 purpose。显式治理任务不得借新参数读取或引用 Dataset。
- 新类别必须固定一个本执行上下文已授权发现的 Dataset/版本；字段 ID 必须来自该快照，1–8 个唯一真实字段，FIELD 至少两个候选。展示名、类型、角色和描述由服务端从发现结果装配，不能由模型提交；保留发现截断说明。FIELD 选项由真实字段装配；TIME/CALIBER 的可选答案是 AI 提问建议，不升级为源口径。
- 问题非空且≤2048 UTF-16 units；选项≤8、各非空≤512、不可重复；新投影 JSON≤12000。字段标识≤128、名称≤256、类型≤64、角色≤32、描述≤512；超限拒绝该反问并回喂固定错误，不截断字段后冒充完整语义。旧问题无结构化类别时不伪造来源。
- 守卫在预算预占之后、SDK 挂起之前校验；非法或未发现引用不创建 pending、不运行查询。新投影写入原 suspended ToolUseBlock 的 content，ID、工具名及原模型入参保持；事件、恢复和原会话使用同一问题文本，不新增 pending 存储。
- 一个 acting 批次有澄清请求时拒绝同批 run_dataset_query，等待用户应答；同批多个澄清请求全部回喂固定错误，不创建歧义 pending。该批次守卫只在原执行上下文内存在，不持有业务状态或替代 SDK pending。它不能证明模型在更早步骤已识别所有语义歧义。
- 有关键字段、时间边界/时区/时间字段、聚合/去重/单位/过滤条件歧义时先反问；不能以“合理默认值”决定会改变业务结果的口径。已明确的项目不重复问；全量统计若用户明确要求可无时间过滤。相对时间先读原日期事实；复合口径没有稳定 Dataset 映射时说明缺口，不从 Metric 定义临时生成 SQL。
- UI 显示类别、数据集 ID/发现版本、字段依据及截断提示，纯文本渲染；提示为生成时字段，不代表当前有效或查询获准。只有原 pending 存在、权限/加载/活动状态允许时才能显式回答；选项零自动提交，自由回答≤2000。切会话/项目/待答 ID 后清理未发送答案，迟到回调沿原 generation 隔离。投影损坏显示固定提示并阻止回答，不把坏 JSON 当可回答的原文。
- 原兼容纯文本及 question/options JSON、治理反问不回归。恢复仍匹配原 toolCallId/toolName、同一 turn/CAS/预算；执行恢复后的新上下文不复用旧字段发现，实际查询重新授权及版本/白名单核验。展示/选择不调用源查询。

## 边界与未决项

Domain Impact：原 Session/Turn/PendingClarify、DatasetFields；不改变生命周期。Architecture/Dependency Impact：runtime 内部反问边界消费已持有的 domain 字段快照，前端共用解析器与原页面卡片；不新增跨模块依赖，Dataset 源域不需改动。

本批不新增任意 SQL、多 Dataset 联查、口径计算引擎、查询审批/确认工作流、自动业务写入或长期知识库。服务端可核验字段身份与载荷，不能证明模型已识别全部语义歧义，也不能把用户回答变成源定义。真实错题及语义评分按用户要求后续统一采集，不宣称准确率或节省时间。
