# F-013 — 质量规则候选核对与人工采纳

Status: IMPLEMENTING

Product basis: ACCEPTED PD-001/PD-002；复用 IMPLEMENTING F-010/F-011，历史解读仍遵守 F-012。

## User / Problem / Capability / Expected Outcome

质量治理人员在原监控编辑器核对 AI 候选。现有逐条采纳缺少与当前表单的对照，重新生成可重复追加同条件规则，异步校验与保存可交错。提供可见对照、保守去重、采纳与保存互斥，帮助用户明确追加内容并人工完成保存。工程依据见 [V5 计划](../../ai/AGENT_V5_PLAN.md)，不是生产试点结论。

## Journey / Truth Owner / Producer / Consumer / Reuse

原监控编辑器生成 → 查看本轮证据和同模板/字段当前表单规则 → 逐条选择 → 源域校验 → 追加停用规则 → 原保存 → 原详情回读；运行保持独立动作。

Quality 拥有监控定义、校验、指纹条件保存、执行计划与结果；Security 拥有授权。Quality 快照/校验 API 是 producer；Agent 与原编辑器是 consumer。复用 AgentScope、现有轮次/HITL/预算/取消、服务器候选与证据协议、原 Policy/审计。表单对照仅为临时呈现，不产生第二份业务真相。

## Behavior / Failure / Scope

- 对照只比较当前表单同模板 ID、同字段的规则，包含未保存修改，最多展示五条并标明其余数量。候选的模板单位沿用原模板显示，不推断跨模板等价。
- 相同条件按模板/字段/操作符/阈值/区间/枚举集合/SQL 保守比较，忽略展示名和 enabled；保留字段及枚举值大小写，不做别名、跨模板或逻辑蕴含推理。阻止 AI 重复带入，不禁止原编辑器人工重复配置。
- 不同条件仅追加、不替换或合并旧规则。删除已带入条目后允许再带入。每次源校验、返回后按最新表单再次核对；失败或空结果不追加。
- 校验与保存互斥，保存前锁定本次内容。切目标/取消后的晚结果不能追加；未授权不可采纳；已有定义冲突仍由服务器 CAS 拒绝，失败保留编辑。
- 新增规则固定 disabled；“带入”仅为未保存表单状态。生成/校验不写源域，不自动启用、保存、调度或运行。原保存可能同步任务版本，启用后可能影响后续运行，沿用原提示。

无新导航、模块、状态机、长期建议/采纳库、业务写工具、源读取契约或框架迁移。第四版未来 P1 的真实试点前置条件仅对上述可复现工程缺口提前实施；真实开放门槛及错误类别/跨执行扩展门槛保持。
