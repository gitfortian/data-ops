# F-022 — 分析报告安全留存与读取恢复

Status: IMPLEMENTING
Approval: 用户于 2026-10-07 授权规划多个版本并依次实现，本版 V14，在 V13 本地回归后实施。
Product basis: ACCEPTED PD-002；既有 Agent 分析报告需求及 IMPLEMENTING F-009/F-011/F-019 的不可信输出/读取纪律。

## User / Problem / Capability / Expected Outcome

分析用户查看并导出本人已保存报告，需要得到对应报告的可安全离线阅读文件。现有 HTML 将标题直接插入、在文件里运行 CDN Markdown 解析且不净化正文，详情晚返回会覆盖后选报告。提供净化的静态 HTML、原 Markdown 导出，隔离列表/详情/下载请求并明确失败恢复。

## Journey / Truth Owner / Producer / Consumer / Reuse

原分析报告页 → 本人报告列表 → 查看明确选中的报告 → 明确导出 HTML 或 Markdown → 本地阅读；详情加载失败可在原弹窗重试。AgentReportService/报告仓储是 producer/唯一 report owner，原报告页与下载文件是 consumer/快照；复用原 REPORT_READ、REPORT_DELETE 与当前用户归属。不新增共享、发布、订阅或 Project 访问规则；报告现有本人范围不是新项目授权。

## Behavior / Failure / Scope

- HTML 在原前端使用已安装 marked + DOMPurify 转换/净化，标题转义。文件无脚本/远端资源加载，使用 CSP 限制脚本、网络与表单，HTML/Markdown 下载明确区分。图表围栏保留 JSON 配置供核对，静态导出不承诺交互图；提示与按钮准确说明，不把失败图伪装成图表成功。
- Markdown 导出为服务器本次返回的原报告正文，不调用模型/改写/保存报告。每次导出重新读取原授权详情，标题/正文来自同一详情且核对 ID；文件名去除控制/路径字符并限长，不信任列表过时标题。导出文件是当次快照，回链仍需原站权限。
- 同步阻止重复导出；卸载、读权限失去或被取消的晚响应不得下载/通知。下载异常固定说明，释放对象 URL；无自动导出或后台模型调用。
- 列表只呈现最新请求，读取失败清除不匹配旧结果并提供重试；详情切换/关闭/卸载隔离晚成功与错误，加载新报告立即清空旧正文，错误留在原弹窗可重试。
- 无 REPORT_READ 时不发列表/详情/导出且不展示正文；无 REPORT_DELETE 时不可删除。服务端仍拥有权限/本人归属裁决。删除保留原明确确认，删除成功后刷新当前查询，不因旧请求回到旧搜索。

无新报告持久化、导出后审批/分享制度、远端依赖、报告自动生成或治理报告保存工具。原正文拥有者不变，既有页面内交互图渲染保持。

## Acceptance / Success Signal

RE01 标题/正文注入与外部资源拒绝；RE02 静态 HTML 离线可读/图表配置保留；RE03 Markdown 原文与同一详情标题/ID；RE04 双击/失败/卸载零晚下载；RE05 详情乱序/关闭/失败重试；RE06 列表乱序/失败/权限；RE07 原删除确认/当前查询刷新及完整发行 CI。

真实模型报告、登录态本人权限与浏览器下载/离线检查 RE01～RE07 独立 PENDING；自动化仅工程证据，Feature 保持 IMPLEMENTING。成功信号为真实用户能稳定查看选定报告并获得可核对文件，无现成收益基线。无阻断产品问题。
