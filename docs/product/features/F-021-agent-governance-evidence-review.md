# F-021 — 治理回答的证据核对

Status: IMPLEMENTING
Approval: 用户于 2026-10-07 授权多个版本规划并依次实现，本版 V13。
Product basis: ACCEPTED PD-001/PD-002；IMPLEMENTING F-009/F-010/F-016/F-020。

## User / Problem / Capability / Expected Outcome

治理运营者核对 AI 回答时，需要知道哪些来源已读取、哪些为空/不适用/不可用/无权读取，并找到原来源。现有卡片只显示英文状态，多块证据或重复 ID 可能造成歧义。提供五态中文含义、来源与读取时点、状态筛选、缺少有效证据提示，拒绝歧义关联。

## Journey / Truth Owner / Producer / Consumer / Reuse

原聊天历史或编辑器候选 → 查看证据总览/筛选 → 核对来源、对象、读取时点、源更新时间与核验值 → 原页面继续。Source API 与服务端证据登记是 producer；原共享证据卡是 consumer。源域拥有业务事实，StateStore 拥有已保存消息，卡片只是原消息投影；复用原证据/事实协议、内部回链、源权限及原导航。

## Behavior / Failure / Scope

- 保留五态原义，OK 仅表示读取成功；EMPTY 不推断健康或无下游；不可用和拒绝不是空，NOT_APPLICABLE 不是失败。显示证据 ID、来源、对象引用、读取时间、源更新时间；未知更新时间不猜新鲜度/过期阈值。
- 新最终消息证据时间编码为 ISO 字符串；历史编码器产生的有限非负 epoch-seconds 数值仅在原前端投影转换为 ISO 毫秒显示，不重写历史、不猜任意数值单位。
- 同一回答只接受一个 yak-evidence 块；重复 ID（含无效条目与有效条目冲突）拒绝整组展示，不能选第一条。非法独立条目过滤且不能参与事实关联；空/无效证据块显示核对提示，普通无证据消息不强加警告。
- 回链只允许当前服务端实际产生的 Asset detail / Quality monitor / execution / Dataset 路径，拒绝协议、任意内部路由和不合法 ID。普通问数的 Dataset 证据保留，不发源请求、不扩大访问权限。
- 核验值只关联唯一有效 OK ID；相同 evidenceRef/field 的重复值不选择其一。事实块歧义不显示核验值，不影响原正文。
- 筛选只作用于本段回答的已有证据；更换回答重置筛选，不能把其他回答事实合入。原聊天与编辑器共享同一呈现。

无新源读取、权限、状态机、时效业务规则或事实 owner；不计算健康/风险分数，不承诺引用存在即语义正确。

## Acceptance / Success Signal

EV01 五态说明不混淆；EV02 总览/筛选/回答切换；EV03 来源/时间未知/原回链；EV04 多块/重复/非法 ID/路径拒绝；EV05 事实唯一 OK 关联与重复字段拒绝；EV06 原聊天、候选及发行回归。

真实 EV01～EV06、登录态源权限与专家判断全部 PENDING；工程证据单独记录。成功信号为真实使用者能区分证据缺口与已证实问题并回源核对，当前无收益基线。无阻断产品问题，Feature 保持 IMPLEMENTING。
