# IA-550｜菜单真实截图评审返工：去三级化 + 去“专业工具”杂项

日期 2026-10-14。状态：实现待实际浏览器验收。依据 #513 / #550，最直接的产品证据是用户对已合并 #571 提供的**真实侧边栏截图**：`业务语义 → 业务域`、`数据标准 → 数据标准` 形成三级重复菜单；孤立的“专业工具 4”迫使用户离开原业务上下文寻找功能。这次纠正上一 PR 的 IA 误读，不以 20 个默认任务标题数量为 KPI。

## 页面预期

五个一级业务域、首页、我的待办、平台设置继续保留，沿用产品原 Logo、快速创建、字体、色彩和 Yak Sidebar。

**展开任一业务域后，直接出现真实可点击页面（最多两级）**：

- 标准、指标与建模：灰色小标题“业务定义”，直接“业务域 / 业务过程”；“标准规范”，直接“数据标准 / 标准字段”（“数仓分层”同组更多）；“模型工作台”直接打开 `/modeling`；“指标体系”直接“指标管理”，同组更多可打开“指标血缘 / 影响分析 / 指标标签与统计”。
- 数据接入与集成：“数据源”，同组更多查看 SQL 执行记录；“数据同步”直接“离线同步 / 实时同步”；“文件资源”直接打开原路径。
- 开发与运行：“开发工作台”；“工作流定义 / 工作流实例”；“发布中心 / 开发运行记录”。
- 资产治理：资产发现、资产治理、技术元数据、数据质量、数据安全、生命周期、主数据管理，各页归入真实业务邻居，如“元数据概览 / 采集与对账”、“质量检查记录 / 规则模板”。单个分组其他页用“更多 N 项”，不添加“专业工具”总入口。
- 数据消费与服务：数据产品目录、数据集管理、API 服务目录、仪表盘/数字大屏直接可达；调用方密钥/API 调试/调用日志归到 API 同组“更多”中。

不把“任务分类”变成需要点击的空壳，**分类标题不可点击**；只允许一级域开合 + 真实页面链接，部分低频同组页面额外一个内联“更多 N 项”披露，没有独立“专业工具”二次分类。桌面折叠仅图标模式使用 Ant 菜单的纯静态分组 caption + 直接路由，**不需要再次打开第二重弹出 submenu**。移动导航沿用相同结构，点击页面链接自动关抽屉。

## 技术与权限防回归

- `appRoutes`、`config/routes.ts`、旧目录地址、`parentId`、业务 `menuCode` 和 `permissionCodes` **完全未改**；无 Flyway、无新 Agent/Workflow/Model Owner 接口。唯一权限输入仍来自原 `getMainNavigationGroups`。
- 只有 SQL Audit Read 而没有 Source Read 时，SQL 执行记录作为“来源管理”范围内的直接链接；只有 API Access / Observe、Quality Execution Read 的角色同理，无需其它根功能授权。没有业务页面的角色不看到空壳栏目。
- 通过原 URL 进入指标影响、数据安全审计、质量检查等低频页面，菜单自动在对应业务组展开“更多”并高亮正确的**真实原页面**；权限变化或切换 Project 后菜单基于授权模型重算。
- 所有当前用户实际可见原叶子必须在菜单中可发现且**恰好一次**；功能开关关闭的 route 不应在导航中出现。

## 合并前人工验收（实际运行的 React，不是原型）

1. 使用正常账号打开【标准、指标与建模】。第一眼看见“业务域、业务过程、数据标准、标准字段、模型工作台、指标管理”，点击“数据标准”**一次直接进入**标准页面；页面中不能出现重复“数据标准 → 数据标准”或“业务语义 → 业务域”的两重按钮。
2. 检查五个一级域：没有任何“专业工具”或专业工具数量计数；更多页面应原地归属业务模块，不跳到不相关区域。
3. 【数据资产与治理】打开技术元数据组，点元数据概览、采集与对账，保留旧路径。质量检查、规则模板和安全审计同理。检查旧页面高亮和刷新返回。
4. 对 SQL-only、API access-only、observe-only、quality-execution-only 授权账号确认可访问唯一授权页面；无权的邻近主入口不能因此出现。
5. 浏览器缩小侧栏后，领域图标弹出菜单中的页面**直接点击可达**，无三级箭头；移动 320/390/768 宽度的抽屉链接可点击、无溢出、点击后自动关闭。键盘 Tab/Enter/Space、焦点和语义标签均检查。
6. 旧 J1 数据源 → ODS、Semantic → 逻辑/物理页面 URL、Metadata 旧重定向地址 106+4 不受影响；跨 Project、撤权和独立专业页旧链接不新增权限父链。

**签收边界：** 当前是可手工复测的生产导航纠偏，自动 Jest/菜单契约/TypeScript 是工程证据；尚未获取对应主线 React 的真人 UX 截图、角色/项目 E2E，不把 PR 合并当视觉产品签收。
