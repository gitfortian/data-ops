## 三、品牌及能力边界

原型视觉从偏绿色换成**红 / 白 / 黑**：品牌强调红、主体白、导航/文本黑与深灰；绿仅允许用于明确的业务成功状态。静态 HTML 的预览色号不能代替生产项目已有 Design Tokens、组件库与菜单样式。生产实现必须复用项目现有规范。

仍保留 V3.1 全域导航；开发/接入/消费及其它非目标域继续为标记明确的占位。PR #553 维持 Draft，**不改变正式 `data-ops-ui`、业务 Owner、菜单、权限、J1、Agent 或数据库迁移**。

## 四、11 项可重复执行的 v0.5 逻辑验收

- 模型草稿编辑后主动切换→继续编辑：恢复原模型/输入且无重复弹窗
- 保存 A→更改 B→放弃：恢复 A，保留不可变历史
- 退款业务过程+会员标准进入模型：必须选择目标，浏览不修改订单模型
- 只读角色可看关联变更，但不能确认写入
- 校验通过、尚未保存：标题/结果状态一致
- 治理历史已提交后再次编辑：本次显示未提交，旧提交不代替当前完成
- 资产、质量与项目专业工具使用主列表优先布局定义
- 治理任务条目可见 P0、Owner、等待时间和点击处理
- 指标连续两次发布得到 v1.2 和 v1.3 两个精确版本
- 来源模型有关系但检索无匹配时，不误称无关系
- 保存新建草稿后可从草稿列表继续完成该草稿的内容

## 五、设计签收阻断项

仍须在真实浏览器复核：1366 / 1024 / 768 / 390 / 320px 任务区和导航、实际可用宽度与长文本换行、弹窗与选择后的焦点/滚动、浏览器 Back、键盘/Esc、色彩对比度。专项治理与标准维护完整业务仍需下一轮 User Story 深化；不应在这些门槛未过前推动大面积生产页面重构。
