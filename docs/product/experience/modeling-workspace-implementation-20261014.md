## 第一版界面

- 默认“分层全景”：ODS → DWD → DWS → ADS 四个设计区域；DIM 作为跨层基础单独呈现。列表与覆盖矩阵继续位于原工作台，无新一级菜单。
- 每层调用原模型分页，`pageNo=1 / pageSize=2`，数量使用服务端 `pagination.total`。包含未关联业务过程的模型；不通过当前页记录推算项目总量，不拉取无界模型列表。
- 业务过程覆盖使用原 `/modeling/mainline`，与每层模型读取独立容错。过程读取失败不清空其他层模型；单层失败显示未知数量和重试提示。
- 全景按已核验过程或所选业务域限定模型读取。过程 URL 继续由 Semantic Owner 解析，未核验前不读取该过程的分层模型；Project/过程变化使旧响应失效。
- “查看模型”进入已有分页列表，清除不属于全景范围的标签、关键字、状态和目标库过滤，保留过程/域上下文。`view` 与 `layerCode` 支持刷新与返回列表。
- “新建设计”复用原创建抽屉，只预选当前项目已配置的层；名称/过程/业务依据与正式提交仍由原表单及服务端核验。缺少层配置给出原 Semantic 数仓分层入口。
- 详情按层提供业务设计、结构、来源和版本快捷路径。每个入口复用原未保存草稿确认；取消离开保留编辑。
- 明确放弃表结构草稿后重置保留在 Tab 中的编辑器，避免草稿继续存活并反复弹窗；空字段模型不显示“全部已治理”。
- 业务过程与开发交接 Tab 改为实际归属信息和现有专业入口，移除占位技术编号。返回工作台按当前模型的真实分层/过程重新筛选。
- 沿用 Ant Design 当前主题 token、YakButton、项目中性色、字号和边框样式；不引入原型配色、外部 UI 库或独立视觉主题。

## 接口与范围

后端、schema、状态机与发布规则均无变化。使用既有分页、主线、Semantic、创建与详情接口，不持久化第二份粒度、维度、运行或旅程事实。

原型里的结构化粒度/可加性、SCD 加工、多事实模型派生与跨模型冻结引用等仍按原提案单独治理。此版主要重构工作台组织、上下文与页面交互；原逻辑、物理、映射、版本编辑能力继续由现有页面承载。
