# R13 DWS 工作台 UI 实施记录（UX-4 / Slice 1）

> 日期：2026-10-18。当前交付：**DWS 设计工作台与静态设计校验 UI**。本 PR 不代表真实样本查询、SQL 执行、数据落仓或运行后对账完成。

## 1. 产品基线与改动

本实现依据已合并的 [R13 UX-2 DWS/ADS 高保真设计](https://github.com/gitfortian/data-ops/pull/596) 与 [逐屏验收证据](R13-UX2-DWS-ADS-hifi-review-and-browser-evidence.md)。改动仅在现有建模模型详情的 DWS 粒度合同面板中实施，保留 data-ops 已有导航与模型编辑壳，不重复绘制全局导航。

- 将旧的单卡片 DWS 粒度表单改为工作台式布局：来源与版本、统计粒度、度量与校验、右侧设计校验/三层证据/冻结合同摘要。
- 保存物理结构仍为前置条件；粒度合同继续复用已有 Modeling API 与 CAS/结构指纹，不另造数据模型。
- 静态设计校验可检查物理结构保存状态、IANA 时区、周期桶必须在分组维度中、维度/度量标准绑定和聚合函数、上游候选可用性及来源版本漂移。
- 任何输入、来源或版本变化都会使上一轮静态校验标为 `STALE`；只有当前签名的校验 PASS 才能启用保存。
- 保存成功后清除旧校验结果，并以新合同修订重新校验。物理结构变化可重新校验并保存新的合同修订，不会因旧指纹永远阻断修订。
- 如果保存响应超时，先读取同一模型的已保存合同，逐项比对字段、结构指纹与精确上游发布版本；回读不匹配时明确显示“结果未知”，不盲目重试或声称成功。
- 已冻结来源从 V2 漂移到 V3 时显式要求选择：保留原冻结合同（只读，不允许伪装为可发布）或确认迁移到当前发布版本并重新校验。不会静默升级来源。
- 增加可展开的固定合成样本例子：3 条订单明细、COUNT(*)=3、COUNT DISTINCT(order_id)=2、行金额示例和 450。所有结果标记为“合成示例/非真实查询”，不会修改 V1/V2 状态。

## 2. 三层验证真实状态

| 层次 | 本 PR 实现 | 不能声称 |
|---|---|---|
| V0 静态设计校验 | 浏览器基于当前表结构/粒度合同进行可解释检查；后端保存与发布校验仍是最终门禁 | 不证明指标在真实数据上的业务正确性；业务时间列真实存在/类型仍由服务端冻结快照验证 |
| V1 真实只读样本预演 | **尚未接入**；UI 明确标 `NOT_CONNECTED`。固定样本仅为口径教学示例 | 不运行 SQL、不连接数据源、不读取真实明细 |
| V2 运行后对账 | **尚未接入**；明确标 `NOT_EXECUTED` | 不创建 DataDev TaskRevision，不触发 Runtime，不宣称目标数据可消费 |

真实 V1 后续必须先确定受治理 Query/preview API、项目/源表/列 READ 权限、超时/限流/审计与敏感数据脱敏。V2 需真实 DataDev/Runtime ExecutionId、目标表数据、Quality 与可比范围证据。DR-07 #557 的生产写入授权不会因本 PR 改变。

## 3. 验收场景

- 打开已保存合同，准确回读修订、结构指纹、SHA 与冻结上游 Vn。
- 物理结构未保存时阻断校验和保存。
- 无时区/非法时区、缺周期桶、周期桶不属于分组维度、缺标准字段、无有效度量、无已发布 DWD 来源时，展示可定位阻断项。
- 改变时区/周期/来源/版本后，旧静态结果显示 STALE；重新校验才能继续。
- 已冻结 V2、当前发布指针 V3 时，不允许静默保存；只有显式迁移、重新校验并收到 V3 回读才可继续。
- 物理结构指纹变化时允许重新校验并保存新的粒度合同修订；服务端仍按当前结构和上游快照执行强校验。
- 保存响应未知时回读同一模型；只在内容、结构指纹及上游精确版本都一致时确认成功。
- 合成样本只展示 COUNT(*) / COUNT DISTINCT 差异，不修改真实查询/运行状态。
- 全流程不调用 SQL、Runtime、DataDev、Metric 发布或 Dataset/Service 授权 API。

## 4. 当前剩余项

1. 本 PR 的前端 Jest、TypeScript/type-baseline、Product Guard 和完整 Architecture CI 需全部通过后再合并。
2. DWS 真实样本 V1 需另一个纵向能力合同与后端权限/审计设计，不可在前端自行拼 SQL。
3. ADS 应用输出合同、业务键/过滤、Metric 引用与保存回读仍是独立后续 PR，不混入本 DWS slice。
4. DWS 正式发布/运行后对账与消费验收依赖原域能力和授权，不能从设计合同 PASS 推断成功。
