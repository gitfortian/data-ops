# IA-550｜五域任务菜单一次完整交付 · 产品人工验收

日期：2026-10-14。基线：#513 用户故事地图 75 条、#550 IA V3.1 菜单与页面组合、IA-V3.1 106+4 路由去向台账。当前 #550 D1–D5 是产品签收候选（尚未标记正式签署），本 PR 按需求方明确的菜单重构授权进行**呈现层实施**，不擅自更改 Domain 合同。

## 交付内容（一个 PR 可验收）
用户在登录后的现有 SiteLayout 左侧栏直接看到：
1. **工作入口**：工作首页、我的待办（按原权限）。
2. **五个业务域**：数据接入与集成、标准指标与建模、开发与运行、数据资产与治理、数据消费与服务。各域默认只展示规划的 **3 + 4 + 3 + 6 + 4 = 20 类任务入口**，按当前角色只出现有权的任务：
   - 接入：数据源、同步任务、文件资源。
   - 建模：业务语义、数据标准、模型工作台、指标中心。
   - 运行：开发工作台、工作流、发布与运行。
   - 治理：资产目录、治理工作队列、质量治理、数据安全、生命周期、主数据专业工作台。
   - 消费：数据产品目录、数据集、API 服务、分析展示。
3. **专业能力**：每个业务域的非默认合法入口放在域内可展开的“专业工具”。对应旧页面仍存在独立 route/path/权限/MenuCode，点击后仍显示相应已有专业页面；从专业深链接进入，自动展开相应域和工具。**默认任务分组不等于新工作台能力**；如“同步任务”只列出有权的离线/实时两个现有页面，“数据标准”列出原标准/标准字段两个页面，既不冒充后端合并，也不误用同一个授权。
4. **平台设置**：现有授权管理页直接保留，不为菜单缩水把管理权限/Grant 变成新前置条件。移动导航和收窄后的弹出导航复用同样的任务模型。样式继承 Yak 的品牌交互色、灰白视觉、字体字号和现有 icon，不拷贝原型的英文装饰或自造主题。

## 兼容与安全
- `appRoutes` 原 ID、path、component、hidden、`parentId`、`menuGroup`、业务权限与稳定 `menuCode` **完全不修改**；`config/routes.ts` 以及其中 4 条 Metadata 旧地址保留。
- 不修改后端/Flyway/角色 Grant、平台菜单表、功能开关。默认菜单和专业工具都使用 `getMainNavigationGroups` **已过滤的**真实授权路由。视觉归属与权限父链解耦。
- 最小权限场景：只有 `resource:sql-execution:read` 的审计角色、只有 `data-service:access` 的密钥管理员、只有 `data-service:observe` 的运行观察者、只有 `quality:execution:read` 的检查记录查看者，仍能从相应业务域首次发现自己的入口。任务主入口缺权限时绝不展示假的项目级链接。
- 隐藏详情与已有链接、刷新/后退/多 Project/撤权仍由原 `getActiveNavigationId`、RouteAccessBoundary 与业务 API 核验。专业页是旧 URL 的原业务 Owner，不能把点击菜单解读为权限放行。
- 菜单改变可通过回滚该呈现层 PR 回退，不删除任何 RBAC 菜单目录或角色授权。

## 用户验收操作（PR 分支启动后）
1. 用有全部业务域授权的管理员打开主菜单：默认每域依次出现 3/4/3/6/4 类任务。首页、待办、平台设置分别保留；默认不再看到旧几十个并列专业模块。
2. 展开“标准、指标与建模”：点击“业务语义”展开看“业务域 / 业务过程”；“数据标准”展开看“数据标准 / 标准字段”；点击“模型工作台”打开当前正式工作台。确认逻辑模型的旧深链接仍按原 route 可访问，详情侧栏高亮模型工作台。
3. 展开“数据接入与集成”：同步任务显示有权限的“离线同步 / 实时同步”原页面；数据源打开后走 J1 → ODS，菜单不会吞掉来源 ID/Schema/表。到本域“专业工具”能找到 SQL 执行记录。
4. 展开“数据资产与治理”：默认“资产目录 / 治理队列 / 质量治理 / 数据安全 / 生命周期 / 主数据”。打开“专业工具”能找到 Metadata 概览、项目级采集与对账、全局血缘、质量检查记录/规则模板等原专业业务。
5. 展开“数据消费与服务”：数据产品目录与数据集各自独立；“API 服务”仍是生产者，“专业工具”应有调用方与密钥、运行概览、调用记录。不能把无 API 目录权限的密钥管理员挡住。
6. 收窄为仅图标模式：点开各域能找到同样的默认任务与专业工具；手机 320/390/768 视口 Drawer 同样可见。检查键盘 Tab、Enter/Space、Escape、焦点可见，切换业务域不会出现多个幽灵可聚焦链接。
7. 最小权限真实账号 + 双项目切换 + 撤权：菜单项不泄露其他角色链接，深链仍受原 RouteAccessBoundary 保护。返回/刷新后自动打开所属业务域与正确工具，不在页面未加载时错亮其他菜单。
