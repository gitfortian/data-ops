# IA-550｜双栏导航整体交付与人工验收

日期：2026-10-14。来源：#513 用户故事地图、#550 IA 规划，以及用户对 #571、#572 实际页面截图的否决。用户明确批准：“左侧全局导航 + 右侧当前业务域菜单”，要求**实施完成后直接拉取看效果**。本文件说明正式 React 交付（不是纯原型），不替代真实浏览器签收。

## 产品定义

**固定全局栏**（146px）只含首页、我的待办、五个业务域和平台设置，域名用短文案避免小空间挤占；顶部原 Logo/快速创建保留，快速创建压缩至左侧全局栏宽度，避免跨两栏的巨大品牌横条。

**右侧上下文栏**（约 214px）根据当前选中业务域，只呈现该域已获得菜单 + 功能权限的实际业务页面；按现有业务意义显示小字号**不可点击的分组标题**，所有 page 链接一次点击直达，无三级菜单、无“更多 N 项”、无独立“专业工具”。右栏独立滚动，不推动左栏业务域的位置；因此资产治理下更多页面也不会将消费或平台设置挤出视野。

- 数据接入：来源管理（数据源、SQL 执行记录）/ 数据同步（离线、实时）/ 文件资源。
- 标准与建模：业务定义（业务域、业务过程）/ 标准规范（数据标准、标准字段、数仓分层）/ 模型工作台 / 指标体系（指标管理、血缘、影响分析、标签统计）。
- 开发运行：开发工作台、工作流定义与实例、发布及执行记录。
- 资产治理：资产发现与目录、资产治理、技术元数据、质量、安全、生命周期、主数据业务页。
- 数据消费：数据产品、数据集、API 与运行/调试/密钥、仪表盘和大屏。
- 平台设置：沿用原菜单路由和授权，不合并功能，不变更菜单数据库记录。

## 页面尺寸与响应式

桌面可展开的 aside 宽度为 **360px = 146px 全局栏 + 214px 上下文栏**；菜单顶部使用既有品牌 Logo，快速创建仅占 146px 全局栏。顶部 header 和主工作区偏移同步变更为 360px，避免页面被菜单盖住。宽度在 1080px 以下沿用旧版受支持的**64px 图标紧凑侧栏**；该状态每个域图标通过 Ant 的分组菜单直接展示所有授权链接，没有第三层选择菜单；手机（<768px）用最大 400px（不超过屏宽）的双栏抽屉，左右栏各自可用，右侧独立滚动，选择页面后自动关抽屉。

### 不可破坏的后端/权限合同

- 原 `appRoutes` 的路由 ID/URL、`menuCode`、`parentId`、菜单 Grant/权限、隐藏详情页 106+4、旧 Metadata 重定向保持完全不变。
- 右栏**只消费** `getMainNavigationGroups(permissionCodes, menuCodes)` 已验证的路由；任何新菜单项不是权限来源。SQL 审计只读用户、API 密钥 only、运行观测 only、质量执行记录 only 仍需找到唯一有权页面。
- 当前路由经旧 `getActiveNavigationGroupPath` 找到领域。外部深链、刷新、前后退、账号授权变化后，应定位右栏相应域、选中原页面；从首页/待办返回时保持最近选过的业务域，不出现无权链接。
- 不变更本轮 J1 数据源→ODS 和语义→逻辑→物理的后端业务行为。纯导航呈现层，不创建第二套用户菜单状态源。

## 用户一步一步验收

1. 拉取此 PR 的分支运行 UI；在首页应看到**左侧全局栏、右侧当前业务域面板两个并排区域**，最外面的全局五域始终可见；不再是截图中长而深的单栏展开树。
2. 点击左栏“标准与建模”，**只有右栏内容变化**，左栏不滚动、不收起；右栏直接显示“业务域、业务过程、数据标准、标准字段、数仓分层、模型工作台、指标管理、指标血缘、影响分析、指标标签与统计”。每项都是原页面 URL，没有需要点击的二级空壳。
3. 左栏分别切换“数据接入 / 开发运行 / 资产治理 / 数据消费”。仅右侧变化；资产治理页面很多时右侧可滚，左侧平台设置仍可见。SQL 审计等原低频业务页无需先找“专业工具”。
4. 从右栏进入模型工作台，再经原深链进入逻辑/物理详情，菜单仍指向建模域的原 page link。刷新、浏览器返回后领域正确高亮。
5. 检查菜单收起（图标+弹出页面菜单）、1024px 触发紧凑、768px 宽度变化、320/390 手机双栏抽屉。抽屉内点击 page link 自动关闭。右栏滚动时左栏仍固定，不能出现主页面被 aside 遮盖。
6. 用 SQL-only、API access-only、API observe-only、quality execution-only、普通只读角色分别查看，右栏只出现真正授权的页面，不允许父工作台权限误挡独立功能，也不泄漏其他模块。
7. 检查焦点/键盘 Tab、Enter/Space、屏幕阅读器的“全局导航”与当前业务域“页面”分区；字色、选中状态、间距与现有 DataOps/Ant 设计一致。
