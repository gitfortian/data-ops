## 2. DWS 六屏用户故事

| 屏幕 | 主要操作 | 设计核对 |
|---|---|---|
| DWS-01 | 给当前项目/过程创建具名汇总设计，找回历史草稿 | 可恢复同一对象，不从 SQL 开始 |
| DWS-02 | 选择已发布 DWD 订单头或明细 Vn；声明源/目标行粒度 | 未发布候选禁用，不能把订单行看成订单 |
| DWS-03 | 确认时间列、IANA 时区、统计周期、桶及分组维度 | 业务日×城市等粒度可解释，时间桶必须是维度 |
| DWS-04 | COUNT_DISTINCT 业务键及金额来源/重复计量确认 | 函数合法不代表口径可靠 |
| DWS-05 | 独立保存草稿与发布设计，查看阻断清单 | 设计发布不触发 Runtime |
| DWS-06 | 重开草稿、追溯 Vn、独立展示运行/质量/消费状态 | 未验收数据不显示已可消费 |

可点击的负例和恢复：来源撤权、只读权限、金额重复计量真实阻断、DWD V2→V3 差异审阅（显式沿用旧版或升级并重新审阅度量）、保存超时后按对象/修订回读、重新打开相同草稿。

## 3. ADS 六屏用户故事

| 屏幕 | 主要操作 | 设计核对 |
|---|---|---|
| ADS-01 | 定义应用/报表/Dataset/API 目标、使用者及责任人 | 消费目标先于来源 |
| ADS-02 | 默认已发布 DWS，明细需求显式选择 DWD | 切换弹层提示业务键/字段/粒度变化，保存旧稿/确认/取消 |
| ADS-03 | 消费者输出字段、业务键、固定过滤与排序、受限列 | 不自动泄露敏感字段 |
| ADS-04 | 正式 Metric 版本引用、刷新要求、业务与安全确认 | SLA 目标不等于已兑现，Metric 未获批准不自动发布 |
| ADS-05 | 明确阻断项，保存草稿/设计发布分开 | 模型版本发布不等于服务可用 |
| ADS-06 | 重开 ADS 修订、分开展示 Runtime/Dataset/Service/Usage 状态 | 不虚构 API 已授权或 Usage |

可点击负例和恢复：来源模式切换保护已有编辑、Metric 漂移阻断、消费者权限撤销、敏感列阻断、保存状态未知时回读、上游 DWS 未发布不可悄悄降级为 DWD。

## 5. 等待产品审查的专业分歧

- DWS：首版是否只支持一份已发布主事实；如何解释无时间桶的全量汇总；去重业务键、金额过滤/退款/折扣如何交由业务 Owner 确认；多来源关联基数如何限定。
