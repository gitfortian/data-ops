## 2. DWS 六屏用户故事

| 屏幕 | 主要操作 | 设计核对 |
|---|---|---|
| DWS-01 | 给当前项目/过程创建具名汇总设计，找回历史草稿 | 可恢复同一对象，不从 SQL 开始 |
| DWS-02 | 选择已发布 DWD 订单头或明细 Vn；声明源/目标行粒度 | 未发布候选禁用，不能把订单行看成订单 |
| DWS-03 | 确认时间列、IANA 时区、统计周期、桶及分组维度 | 业务日×城市等粒度可解释，时间桶必须是维度 |
| DWS-04 | COUNT DISTINCT 业务键/金额来源及「验证计算」模拟 | 3 明细行≠2 订单；STALE/UNAVAILABLE/SAMPLE_WARNING 有原因和重验 |
| DWS-05 | 核对 V0 静态/V1 样本/V2 运行后对账，草稿与发布分离 | 未处置异常阻断；没有真实数据不能标验证成功 |
| DWS-06 | 重开草稿、追溯 Vn、独立展示运行/质量/消费状态 | 未验收数据不显示已可消费 |

可点击的负例和恢复：来源撤权、只读权限、金额重复计量真实阻断、DWD V2→V3 差异审阅（显式沿用旧版或升级并重新审阅度量）、保存超时后按对象/修订回读、重新打开相同草稿。

## 7. UX-1 新增数据验证能力及评审（2026-10-17）

本轮响应业务指标正确性审查要求，只变更全新 UX-0 产品合同及 UX-1 **可点击模拟**。不引入真实 Query、Metric/Runtime/Quality 执行或生产读写权限。

### DWS-04 / DWS-05

- 内联「验证计算（固定样本模拟）」：O001 明细 100、200 和 O002 明细 150；同日同城 3 条明细、COUNT DISTINCT(order_id)=2、明细金额样例总和 450，**不代表真实支付净额**。
- 切换 COUNT(*) 会把明细行数 3 误作为订单 3，显示 SAMPLE_WARNING 和 +1 差异，DWS-05 阻断模拟发布；修正后可重新运行样本。
- 来源版本/去重键/业务时间/时区/分组/函数或草稿 Revision 发生变化，旧证据显示 STALE；来源撤权、未发布、无时间列时显示 UNAVAILABLE。
- DWS-05 与右侧始终分开显示 V0 静态合同、V1 样本、V2 运行后对账；V2 本原型只能是 NOT_EXECUTED。

### ADS-03 / ADS-05

- 内联「验证输出（固定样本模拟）」：合成 DWS 上海订单 2、金额 450，北京订单 1、金额 120；全部地区 3/570，应用过滤 city_id = 'SH' 后为 2/450。
- 全地区与仅上海的差异应解释为**过滤范围变化**，不是自动判为计算错误；相同范围多一个订单则 SAMPLE_WARNING。
- 模拟输出业务键重复、同范围数量差异、来源/Metric 撤权、受限字段及 DWD 明细粒度不能直接按 DWS 汇总口径验算；结果分别为警告或 UNAVAILABLE。
- 不支持的自定义过滤表达式不构造数据，显示「不可计算/不可比较」。映射/过滤/来源/Metric/消费方/草稿 Revision 变化都将旧样本改为 STALE。
- ADS-05 同时呈现静态设计、样本输出、真实运行/消费验收三种证据，样本成功不意味着 Dataset/Service 已可调用。
