## 范围

依据用户明确要求优化各个页面、弹窗、抽屉的布局与视觉；继续沿用 ACCEPTED PD-003、IMPLEMENTING F-029/F-037 与 Modeling 领域合同。PROPOSED PD-010 / DRAFT F-040 不作为新能力授权。

- 样式只作用于既有建模路由及其 portal 浮层，继承项目现有主色和组件；不改全站配色、侧栏、其他模块或后端接口。
- 五个主入口、模型详情（表结构/来源与分层映射/逻辑依据/版本/交接）、ODS 来源路径均检查；创建、派生、编辑、逆向导入、标准辅助、回收站、标签、逻辑实体/属性/关系、结构导入与证据弹窗纳入排版覆盖。
- 页面标题、说明、主操作分区；嵌入详情的结构与映射不再计算完整视口高度。主要表单按实际内容宽度分列，业务说明和长文本独占一行。
- 浮层标题、内容与页脚各自清晰；长内容在内容区滚动，按钮保持可达；宽表保留水平滚动，代码保持独立滚动，不隐藏字段或截断后宣称完整。
- 所有原保存、取消保护、权限、审批冻结、明确提交与只读证据边界保留。不新增自动保存/发布、运行、业务门禁或派生状态。

## 验证记录

### 实现与静态验证

- 建模路由增加局部 `ModelingLayout`，继承项目主题；统一标题、说明、工具栏、卡片、表单和 portal 浮层的间距，不更换主色。
- 总览卡片和表单以容器实际宽度决定分列；详情中的表结构、来源映射、分层映射使用嵌入布局，避免重复整页高度。影响核对拆为标准字段与来源两组查询条件。
- 创建、派生和基础信息抽屉使用独立页脚；逻辑编辑弹窗与证据浮层统一标题/内容/页脚。Ant Design 选择器优先级和窄屏默认外边距已修正，避免正文贴边和双重滚动。
- 23 个相关 Jest 测试套件、136 项测试通过（建模、导航及侧栏回归）。
- 类型基线检查通过：现有 131 项诊断未增加；未修改类型债务基线。
- 本轮生产代码 Biome 检查、`git diff --check`、`npm run build` 均通过。构建后已重新启动项目开发服务。

### 验收边界

逆向导入、标准辅助、回收站、标签、版本历史、交接与其余证据浮层已纳入局部样式和代码检查；未逐一在浏览器执行所有浮层、权限角色及业务状态。分层映射的嵌入布局已调整，未作为本轮独立浏览器验收项。

本轮没有为了视觉验收创建或修改真实模型、字段、映射、冻结快照，也没有执行发布、回滚、部署或加工运行；未据此宣称业务写入链路、全部角色权限或用户收益已验收。
