5. ~~搜索框清空异常~~（G-A3 已撤项：复测确认真实用户路径正常，初测为自动化工具限制）。
6. **中英混杂**：对账 Section（LIFECYCLE/SECURITY…）、脱敏算法（内置 · MASK_PARTIAL）、合规级别 HIGH 等技术编码直接面向用户。
