Agent 契约预览

Agent 眼中的两层模型：WorldView（世界地图）+ CaliberView（口径字典）——只读视图
1

世界地图 · 理解与决策

search_concepts → get_object_schema：有哪些对象、关系是否允许、规则约束什么、能做什么动作。

2

口径字典 · 怎么算

从 CaliberView 选指标：口径一句话、适用前提（查询必须带什么过滤）、派生链。

3

运行时 · 执行

run_semantic_query → Guard（值域/规则来自本体快照 + 口径来自语义快照）→ 编译 → 数据集执行。

Agent 工具清单（toolset 改造）
工具归属说明
search_concepts本体语义跨两层搜索（对象/指标/术语），结果标注归属层
get_object_schema本体语义返回 WorldView 卡 + CaliberView 卡（不再混装 MetricCard）
list_rules（新增）本体业务规则发现（requires 约束）
list_actions（新增）本体业务动作发现（能力词汇）
run_semantic_query运行时语义查询（Guard → 编译 → 数据集）
run_function语义执行注册函数
get_object_instance运行时实例明细（走绑定层）
run_dataset_query物理字段级明细查询（白名单校验）
设计要点：WorldView 与 CaliberView 是两套独立契约（设计文档 §7）——Agent 判断"允不允许"看 WorldView 的规则，决定"怎么算"看 CaliberView 的口径；两套契约由运行时（semantic-compile）统一暴露给 agent，保持 agent → compile 单走廊依赖。
