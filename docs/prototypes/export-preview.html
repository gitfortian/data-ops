单 artifact（semantic_model + custom_extensions）→ ontology / semantic_model / mappings（对应 Ossie 两规范）
ontology.yaml（本体层，flights.yaml 形状）： EntityType/ValueType 概念、identify_by、relationships（roles/multiplicity/verbalizes）、requires（业务规则）。   semantic_model.yaml（语义层+绑定+数据集，tpcds 形状）： datasets/fields/metrics（SQL 口径）。   mappings.yaml（绑定层）： concept_mappings 把语义字段映射进本体对象与关系。

ontology.yaml · 本体建模层产物
# Ossie ontology · flights 形状（业务世界：对象/关系/规则）
name: SalesOntology
description: 销售域业务世界：订单/客户/商品及其规则
ai_context: 用于销售域问答与决策：先看规则，再选指标
ontology:
  - concept: SalesOrder
    type: EntityType
    identify_by: [order_id]
    requires:                       # ← 业务规则（本体层）
      - SalesOrder.pay_amount >= 0
      - SalesOrder.paid_at <= SalesOrder.shipped_at
    relationships:
      - name: order_id
        roles: [{ concept: OrderNr }]
        multiplicity: OneToOne
        verbalizes: ['{SalesOrder} is identified by {OrderNr}']
      - name: placed_by
        roles: [{ concept: Customer }]
        multiplicity: ManyToOne
        verbalizes: ['{SalesOrder} was placed by {Customer}']
      - name: pay_amount
        roles: [{ concept: Amount }]
        multiplicity: ManyToOne
        verbalizes: ['{SalesOrder} has pay amount {Amount}']

  - concept: Customer
    type: EntityType
    identify_by: [customer_id]

  - concept: Amount
    type: ValueType
    extends: [Decimal]
    requires: [Amount >= 0]          # ← 属性值域（本体层）

  - concept: OrderNr
    type: ValueType
    extends: [String]
semantic_model.yaml · 语义建模层 + 绑定 + 数据集产物
# Ossie semantic model · tpcds 形状（怎么算：datasets/fields/metrics）
semantic_model:
  - name: sales_analytics_model
    description: 销售域指标口径与物理数据
    datasets:
      - name: order_fact
        source: dwh.dwd_sales_order      # ← 绑定层解析（object.datasetId）
        primary_key: [order_id]
        fields:
          - name: order_id
            datatype: String
            dimension: { is_time: false }
          - name: pay_amount
            datatype: Decimal
            ai_context: { synonyms: ["支付金额", "实付"] }
          - name: order_status
            dimension: { is_time: false }
    relationships:
      - name: order_to_customer
        from: order_fact  to: customer_dim
        from_columns: [customer_id]  to_columns: [customer_id]
    metrics:                               # ← 语义建模层（口径，独立于规则）
      - name: gmv_paid
        expression:
          dialects:
            - dialect: ANSI_SQL
              expression: SUM(order_fact.pay_amount)
        ai_context:
          caliber_filter: order_status == '已支付'
          exclusions: ["不含已退款部分"]
          synonyms: ["GMV", "销售额"]
      - name: avg_order_value
        expression:
          dialects:
            - dialect: ANSI_SQL
              expression: SUM(order_fact.pay_amount) / COUNT(DISTINCT order_fact.order_id)
mappings.yaml · 绑定层产物（Ossie Ontology mappings）
# 本体对象/关系 ← 语义模型字段（object_mappings / link_mappings）
concept_mappings:
  - concept: SalesOrder
    object_mappings:                      # ← 本体对象实例化（对象→数据集）
      - expression: order_fact.order_id
    link_mappings:                        # ← 本体关系实例化（属性→字段）
      - object_mapping:
          concept: Amount
          expression: order_fact.pay_amount
        relationship: SalesOrder.pay_amount
      - object_mapping:
          referent_mappings:
            - relationship: Customer.customer_id
              expression: order_fact.customer_id
        relationship: SalesOrder.placed_by

  - concept: Customer
    object_mappings:
      - expression: customer_dim.customer_id
设计要点：对应设计文档 §8.4——规则进 ontology 产物的 requires，指标口径进 semantic_model 产物的 metrics，锚定进 mappings；custom_extensions 不再承载本体内容。迁移映射见设计文档第 8 节。
