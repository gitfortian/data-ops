设计要点（对应文档章节）
① 本页是"盘点→上架"治理工作台：台账来源全部机器登记（对账），人只做确认、补齐、上下架三类动作（需求 §3.1/3.2）；
② 上架向导 = 预检（逐资产缺口+一键补默认）→ 风险确认 → 5 分钟 token 防盲发 → 逐条结果（design §6.2，对齐 lifecycle"预览确认 token"先例）；
③ 变更确认列表展示字段级 diff 而非整行覆盖：源域事实变化必须经人确认才同步进台账（D1）；
④ 源接入 Tab 体现 provider 分域容错：TASK 域失败不阻塞其余四域（design §6.1），失败可见可重试；
⑤ 下架复用同一向导骨架，但强制"原因必填 + 下游引用预览"两步（本页因已上架未演示，见资产详情"下架"按钮）。
