设计要点（对应文档章节）
① 目录/规则/标签三块都遵循「能默认就不填」：编码自动生成、模板一键初始化、名称自动带出（交互原则 §3-§4）；
② 规则是预编目器不是同步器：只在新登记与显式"重新应用"时生效，且首条命中即停（priority 小者优先，design §4.4）；
③ dry-run 是启用前置闸门（错误码 48010），报告展示"将命中/将变更/跳过"三类计数，杜绝规则误伤；
④ 与 security 分级标签的边界用色板与文案双重区隔：本域标签面向消费语义（能不能用/重不重要），分级面向合规（敏感不敏感），互不覆盖（D5）；
⑤ 未分类目录 = 兜底规则目标，保证每个资产永远有归属，概览"未编目"计数恒为 0 可信。
