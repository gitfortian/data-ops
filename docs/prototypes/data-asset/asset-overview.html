设计要点（对应文档章节）
① 本页全部指标服务端聚合 + 固定 ≤8 次查询（D11，home-overview-contract），失败区域显示"暂不可用"而非 0； ② 类型/分层/定级数据均为快照（D1），口径悬浮注明"来源域 + 对账时间"； ③ 待办区每项跳转即带上对应过滤条件的资产列表（预置 URL 参数），处理动作全部发生在盘点工作台与目录页，本页不承载操作； ④ 源接入健康是 Provider 分域容错的体现：单域失败不影响其余域对账（design §6.1）。
