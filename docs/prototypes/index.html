两层建模 · 前端原型

本体建模（业务世界） + 语义建模（口径字典） · 对应设计文档 docs/two-layer-modeling-design.md

一、分层总览

本体建模层

业务世界长什么样

业务对象、关系（roles/multiplicity）、业务规则 requires（声明式约束）、业务动作、术语。声明式，与物理数据无关。
语义建模层

怎么算

指标口径（聚合+过滤+派生+单位+时间粒度）、适用前提、函数。引用本体属性，口径独立定义与演进。
绑定层

本体 ↔ 数据

对象→数据集、属性→字段（Ossie Ontology mappings）。锚定一致性、失效监控、join 命中率。
运行时

守卫+编译+执行

读两层快照：值域/规则来自本体，口径来自语义；编译为数据集查询。Agent 唯一执行入口。

二、原型页面

本体改造

本体画布

三栏布局：对象列表 / 对象关系图 / 检查器。业务规则 requires 条件构造器、业务动作、术语表。指标入口已剥离。打开原型 → 语义新增

语义建模 · 口径字典

指标库 + 口径编辑器：聚合/过滤/口径例外/派生链/适用前提/审计引用（只读）/版本与发布闸门。打开原型 → 绑定新增

绑定管理

对象→数据集、属性→字段映射总览；锚定健康度（BROKEN/命中率）；重绑与重校验。打开原型 → Agent新增

WorldView（世界地图）与 CaliberView（口径字典）双契约，工具清单与三步决策流。打开原型 → 导出新增
