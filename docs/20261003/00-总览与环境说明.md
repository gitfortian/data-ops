## 跨模块共性问题（建议统一治理）

1. **空表/空态下的横向滚动条**：几乎所有 antd Table 页面在无数据时仍渲染超宽表格，一条深色横向滚动条压在空态插画下方，观感廉价。涉及：离线同步、实时同步、发布中心、开发运行记录、资产目录、采集与对账、元数据概览等。建议：空态时不渲染表格框架，或 `scroll.x` 自适应容器。
2. **列头/单元格裁切**：表格列宽分配不均，出现"近30…"、"照…"、"批…"、"版…"等被裁切的列头（资产目录、标准字段、数据标准、发布中心）；"数据源类型"标签断词换行；项目空间"创建时间"被裁成 `20 / 09` 两行数字。
3. **0/0 语义**：无数据时显示 `0%`（质量报告表质量通过率、SQL 执行审计成功率），应显示 `--`（首页质量卡已正确使用 `--`，标准不一致）。
4. **原始枚举/内部值外露**：数据源类型抽屉显示 `POSTGRE_SQL`/`OPEN_GAUSS`/`SQL_SERVER`（开发节点菜单却用 `GBase 8c` 友好格式，两处不一致）；操作日志"资源"列显示 `DATA_QUALITY_MONITOR` 等枚举；数据源卡片时间显示原始 ISO 串 `2026-10-03T…`。
5. **长 ID 精度丢失**（见 03 分册 DEV-04）。
6. **危险操作保护良好**（值得保持）：删除需二次确认、未发布不可运行、已配置监控的表不可取消注册、在线任务需先下线才能删除。

## 环境与测试过程说明（透明度声明）

- 测试开始时前端/后端/MySQL 均已在运行，无预置业务数据（默认工作空间为空），所有空态验证均为真实首跑。
- 测试中途（约 18:20）**前端 dev server 自发崩溃退出**（进程消失，8000 端口无监听），属于稳定性问题；随后按 10-01 报告记录的绕过方式重启成功（启动后 8 秒内预生成 `src/.umi/plugin-tailwindcss/tailwind.css`，绕过 tailwindcss 插件 60s 超时）。绕过方式每次都有效，进一步证明 S0-01 根因是插件目录未预创建，而非 tailwind 慢。
- 测试数据全部使用 `QA0x-` 前缀并已清理：数据源、离线同步任务、文件资源、业务域、SQL 节点（发布 V1 后下线删除）、工作流草稿、质量注册表与监控均已删除。按设计保留的：操作日志（40 条审计记录）、质量执行历史记录。
- 测试账号 root 在测试中产生 1 次错误密码登录尝试（验证登录失败反馈），不会触发 15 分钟锁定（阈值 5 次）。
