## 划分口径说明

1. 图二中的独立节点原则上各出一份文档（28 个业务模块），与后端 `yak-ops-business-*` 目录基本一一对应。
2. 「离线同步 / 实时同步」共用后端 `yak-ops-business-sync`，但按图二为两个独立能力节点，各出一份文档并在文中说明共享关系。
3. 「任务目录 / 任务内核 / 工作流」在图中是④段三个独立节点，各出文档；三者间锁版本引用关系在各自第 5 节交叉说明。
4. 「仪表盘 / 大屏」合并核查乱象 R-4（两套草稿→版本→发布机制是否重复），但仍是两个模块各出文档，核实结论在两份文档第 7 节互相引用。
5. 不作为业务模块单列的：数据库、调度中间件、common/core/spi 框架层、`system/settings` 平台设置页（并入「首页与平台框架」的附注，不单独治理）。
