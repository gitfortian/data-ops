# 03: 指标值查询/试算(定义编译为 SQL 预览)

**对应需求:** 指标中心盘点 §4/§6(P1)| 阶段: P1

**What to build:** 指标目前是**纯文本定义**——没有任何地方能把 measureExpr/dimConstraint/公式编译成 SQL 去 datasource 执行,平台无法回答"这个指标现在是多少"(旧-工单 48"数据预览(可选)"未做)。本单落地最小试算:原子指标以 measureExpr+来源 DWD 模型+filterExpr+统计周期编译为**只读查询 SQL**,经 datasource 查询通道执行,详情页出"数据预览"卡(取值+SQL 回显);派生指标待 02 组装出表达式后纳入;复合指标公式 token 流→SQL 为硬骨头,可后置或明示不支持。

**模块归属:** **跨模块**——metric(编译器:定义→SQL)+ datasource(只读查询 SPI 执行)

**Blocked by:** 02(派生无可算表达式);原子指标试算部分可先行

**Status:** backlog(待排期)

**硬性约束(不可打破):** 遵守 [gap-backlog 批次约束](gap-backlog-2026-09.md);查询**只读、强制 LIMIT、超时兜底**,严禁新增任何写/DDL 执行通道;datasource 不可达时如实"预览不可用"降级,不阻断详情页(与血缘摘要条同风格);编译失败要给出人话错误而非静默。

- [ ] 经 datasource 只读 SPI 执行,结果+SQL 双回显
