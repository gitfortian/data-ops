## 使用路径

原“分析报告”页查看本人报告，可选择“导出 HTML”或“导出 Markdown”。每次下载重新读取授权详情，核对 ID，并用同一份详情的标题/正文生成文件；文件名去掉控制与路径字符、限制长度。读取失败固定提示，可重新尝试；下载前可取消，取消后的晚响应不下载。

HTML 为经过现有 marked/DOMPurify 处理的静态快照，标题/来源标识转义，正文剔除脚本、表单、外部资源与主动内容，文件内 CSP 进一步限制加载。GFM 表格与普通正文可离线阅读；图表保留 JSON 围栏供核对，不执行交互图、不加载 CDN。Markdown 保留服务器返回原正文，导出不改写/保存原报告。原站链接仍需原权限。

查看新报告先清空旧正文。关闭/重新选择/卸载使旧详情响应失效；加载失败留在原弹窗提供“重试报告”。列表只接受最新查询，失败清空不匹配旧结果并提供“重试列表”。下载同步防双击、异常释放对象 URL；已取消请求不能清除后来下载的请求状态。

无报告读取权限时不请求/展示报告，无删除权限不能删除。服务端仍裁决本人归属与 action permission。删除保留确认，成功后刷新此刻的搜索，不把用户带回发起删除时的旧搜索。

## 工程与边界

Domain Impact：既有报告的读取/下载投影，无新持久化、状态机或 Domain Gap。Architecture/Dependency Impact：原报告页使用原 API 和权限 hook，新增页内 report-export 负责静态格式转换，使用现有依赖；无新服务/接口/走廊。Domain Compliance：report 仍拥有正文，下载只消费当次授权快照，不新增分享/发布/Project 授权制度，后台未调用模型或治理写工具。

真实报告语义、登录态本人权限、真实浏览器下载/离线检查 RE01～RE07 全部 PENDING，工程自动化不替代产品验收；Feature 保持 IMPLEMENTING。
