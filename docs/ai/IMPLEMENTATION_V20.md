# V20 原会话场景结果回看

当前合同 [F-031](../product/features/F-031-agent-scenario-history.md)。用户在合并 #341 后授权继续开发，明确真实模型和测试环境验收后续统一执行。

建模/指标人员从原候选面板进入会话后，可阅读标准匹配、来源字段映射、指标口径解释、指标定义草稿四种交付。卡片展示生成时的候选、原事实、待确认项、Skill 版本及截断提示，并返回原页面重新核验处理。指标草稿正确显示任务标题，历史快照与新建未保存草稿明确区分。

只有授权 history 中唯一 assistant 引用与最新 COMPLETED continuation 的 sessionId/turnId/完整目标一致时呈现卡片；实时 SSE、旧轮无范围证明、重复（包含空 assistant）、坏格式、错范围、读取失败保留原文和固定核对提示。已完成会话也提供刷新入口，重新读取持久化历史。切会话、切项目、失去读取权限或新轮开始后旧卡失效，迟到结果不能恢复已失效内容。

投影复用四种 parser、目标规范化、原回链与请求隔离；没有新端点、源读取或业务写入。卡片不自动带入表单；生成、完成、保存、验证、发布、真实消费证据仍分别核对。当前 continuation 只有最新轮范围，因此不推断较早轮的任务范围。

工程验证见 [V20 验证记录](acceptance/2026-10-08-v20/README.md)。真实模型、登录权限及源操作 E2E 按用户要求 PENDING，Feature 保持 IMPLEMENTING。
