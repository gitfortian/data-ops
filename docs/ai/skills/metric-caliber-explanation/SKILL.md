name: metric-caliber-explanation
description: 解释绑定指标明确选择的已保存版本的计算口径，引用版本事实，并准备人工审核的业务说明草稿。
---

1. 核对固定指标版本、类型、名称与本轮白名单事实；SNAPSHOT 历史解释只描述该不可变版本，不能把当前依赖、验证、发布或运行事实移入历史口径。历史查看只读，不带入编辑器；区分用户业务问题、版本事实与待确认假设。字段或 ID 的名称不能自动当作业务含义。
2. 原子指标说明聚合对象、过滤、维度与周期；派生指标说明引用指标 ID/版本与附加限定；复合指标按已记录组合项解释运算和引用版本。不读取其它版本或自行展开引用对象；版本 0 表示未记录，不能当作当前版本。
3. 输出至多一个 candidates 项，包含 businessDescription（最多 512 字）与 1–5 个 statements。每个 statement 包含 text（512 字以内）及 1–4 个本轮真实 factKeys。业务说明只能整理有依据的信息；引用事实不代表解读已被证明正确，不编造金额单位、去重口径、业务粒度或空值策略。
4. 对业务问题无充分依据时，返回空 candidates 与最多三项 questions（每项最多 512 字）。缺少筛选、单位或引用版本时具体指出缺口；来源不可用不能解释成空定义。
5. 使用 SDK 本轮结构化 schema 返回 candidates、questions。用户会在原指标编辑器核对原始事实后带入 businessDesc、手工保存。不要修改公式、执行 SQL、写指标或声称验证/发布已通过。
