# 字段标准匹配 Skill 材料

此目录是可导入的方法材料，不是第二份运行时注册库。应用只读取原在线管理表 `yak_agent_skill`；部署不会自动登记或启用。

试点管理员先审阅 SKILL.md，再在原“技能管理”登记 `skillId=standard-match`，名称、描述和正文可按 register.json 填写；注册接口仍沿用已有“注册即启用”语义，所以登记本身就是明确启用操作。暂不试点时不要登记，已登记的可在原管理面停用。编辑、停用后版本递增，旧候选不能继续带入。

`register.json` 是已有 POST `/api/v1/agent/skills` 请求体示例；不包含登录凭证、项目 ID 或模型密钥。它不会自动发送。模型只加载这一份 SKILL.md，资源、脚本和额外工具激活均关闭。

同题评测至少包含编号/金额/时间/文本、名称相近但业务不同、目录为空/截断、业务说明缺失和冲突。记录人工选择与候选对照、错误类别及准备时间；未完成真实评测前不得以代码测试通过宣称匹配质量。
