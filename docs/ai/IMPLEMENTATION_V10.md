# Agent 第十版交付说明

日期：2026-10-07
实施权威：[F-018](../product/features/F-018-agent-governance-question-preparation.md)，顺序见 [连续路线](./AGENT_V9_V11_ROADMAP.md)。

在原治理对话展开“准备治理问题”，选择本任务的原问题，按需补充已知背景、希望核对的点和期望结果，查看纯文本预览，再填入原输入框并明确发送。补充内容统一标记为用户提供、尚待源证据核对；不自动补阈值、样本或根因。

支持原资产解读、资产描述候选、质量历史执行排查和监控规则候选。原 GovernanceTarget/purpose、工具矩阵、预算及授权保持不变。治理空状态使用当前任务说明，普通问数保留原示例。

背景上限 2000、重点/期望结果各 1000 UTF-16 units；超限阻止填写而不截断。输入框已有内容时，表单和原快捷按钮均不覆盖。活动、pending、恢复失败/加载及无 CHAT_RUN 时禁止填写；切换/新建/轮次变化重置表单。

表单仅为页面内存，填写不发起 API、模型或源调用；实际发送仍走原服务端，不增加表、接口、配置、权限或导航。纯文本展示避免把输入渲染为 HTML，不承诺提示注入识别或自然语言语义正确。真实验收独立待完成，Feature 保持 IMPLEMENTING。工程检查见 [验证记录](./acceptance/2026-10-07-v10/README.md)。
