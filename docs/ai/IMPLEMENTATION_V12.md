# Agent 第十二版交付说明

实施权威：[F-020](../product/features/F-020-agent-suggestion-lifecycle.md)。连续路线见 [V12～V14](./AGENT_V12_V14_ROADMAP.md)。工程验证与真实验收分别记录，合并/最终 CI 以本版验收记录链接 PR 为准。

## 使用路径

在原资产描述或质量监控编辑器填写业务约束，点击生成。结束后页面读取真实轮次状态；只有完成且历史中唯一明确关联本轮的回答才展示可带入候选。带入、去重、源校验和原页面人工保存保持原约束，新规则仍停用。

排队/推理中、断线或读取失败时不能另发；点击“刷新核对”，或“到原会话查看或继续”。反问来自持久化 continuation，填写后继续原轮。停止只作用于已确认的原 ID，停止后再次读状态；完成或待答先发生时显示实际读取，不宣称停止。

提交无回执时不猜 ID、不发停止；已保留业务约束并提供核对路径。切对象/定义或卸载后晚返回不呈现候选，晚提交回执仅精确清理其自身轮次。取消带入使校验回调失效，不回滚已保存源事实。

## 边界与工程说明

Domain Impact：Aggregate 为既有 Session/Turn/消息引用；无生命周期变更、无 Domain Gap。变更在原前端候选消费边界。Architecture/Dependency Impact：无新服务、接口、持久化或走廊，沿用 AgentChatService/Query 与 StateStore，前端复用现有 service API。

Domain Compliance：候选不成为源定义，SSE 不成为状态真相；自动化覆盖精确停止/同轮反问/读取失败/晚返回，真实模型及源保存审计仍待完成。没有自动跟随、自动推理、自动保存或治理写工具；框架继续 AgentScope Java 2.0.2。
