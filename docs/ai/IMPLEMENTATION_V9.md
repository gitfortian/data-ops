原页面在核对最新终态后解释停止、失败、中断或完成。说明来自固定状态/错误码映射，不把推理完成当作质量通过。用户可点击“填入本轮问题”，编辑并补充背景后明确发送新轮；历史气泡不再重发全局最后问题。

START 草稿来自已持久化输入，并核对可用原消息引用；RESUME 只接受唯一精确原 USER 引用。不提供工具反馈、旧 pending 或猜测的原问题。草稿上限 8000 UTF-16 units，缺失/冲突/读取失败/超限明确降级，允许手工整理。

填写前重读所见轮次与目标；发送携带可选 expectedLatestTurnId，原提交互斥区再次核对最新终态、归属及原任务范围，陈旧来源不建轮。填写不调用模型或源工具，已有输入不覆盖，切换丢弃晚响应。发送同步锁定防双击，提交未确认保留输入并要求刷新；刷新核对也保留未发送编辑。

原普通发送保持兼容，HITL 同轮恢复和预算语义不变。新轮经原 Runtime 重验授权、冻结新预算，旧轮证据/预算/状态不改变。继续使用 AgentScope Java 2.0.2，无新表、配置、导航、权限或依赖走廊。

这里不提供通用提交幂等或多节点强并发保证；原问题草稿不承诺完整重现澄清背景或压缩后的历史。真实模型/登录态及源审计待完成，F-017 保持 IMPLEMENTING。V11 将继续补齐实时停止与断线核对，不以本版替代该范围。
