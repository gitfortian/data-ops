# Agent 第十一版交付说明

日期：2026-10-07
实施权威：[F-019](../product/features/F-019-agent-live-turn-reconciliation.md)，范围见 [V11 计划](./AGENT_V11_PLAN.md)，验证见 [记录](./acceptance/2026-10-07-v11/README.md)。

原实时对话的停止现在只取消提交回执确认的轮次 ID，与恢复页共用原 cancelTurn。回执未确认时不取消未知轮，等待原提交结果；重复停止受同步保护。停止先让原订阅失效并断开，然后读取实际状态；完成或待答竞态以实际读取为准。停止应答丢失只提示核对，不宣称已停止。

连接错误保留已收到的正文和编辑，读取后台 continuation；失败则禁止发送并提供刷新。传输结束不直接确认后台完成，不因断线把执行工具卡或轮次改为失败/停止。读到活动状态后沿用原有限跟随，待答恢复原澄清。

事件、重连、完成、错误与水合响应都核对原 generation；停止、新轮、切换、新建和卸载后的晚响应不得污染当前任务。刷新/停止核对历史失败时也保留已有正文和输入。

继续复用原生命周期、归属/项目权限、工具预算、审计、StateStore 与 AgentScope Java 2.0.2。会话 cancel API 为旧客户端保留，新页面不再调用。无新表、接口、配置、权限、导航、业务状态机或依赖走廊。没有断线自动重新推理、崩溃断点续跑、回滚或多节点保证。真实模型/登录态与源审计待完成，Feature 保持 IMPLEMENTING。
