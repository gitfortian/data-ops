# Agent 第六版：治理会话恢复与继续

日期：2026-10-07

实施权威：[F-014](../product/features/F-014-agent-session-continuation.md)。继续使用仓库 AgentScope Java 2.0.2；本轮不做框架迁移。

## 用户任务与范围

| 必答项 | 本轮定义 |
|---|---|
| User | 返回历史对话继续排查的质量治理人员、资产维护人员，以及等待澄清的问数用户 |
| Problem | 原页面 selectSession 清空治理目标、仅加载消息，不恢复 WAITING_INPUT；刷新也没有会话定位。追问可能丢失原显式任务，挂起会话无法回答 |
| Capability | 按已持久化轮次恢复所选任务、真实状态和待答问题；安全继续或明确阻止 |
| User Journey | 原 AI 会话/浏览器刷新 → 服务器归属与项目校验 → 原消息与最新轮次读取 → 显示任务范围 → 回答原反问或明确发送追问 → 原源页面核对 |
| Expected Outcome | 能找到并继续原任务；加载失败不悄悄变成普通问数，活动轮不被重复提交 |
| Truth Owner | StateStore 拥有消息与 SDK pending；Agent turn 拥有生命周期和已提交任务；源域与 Security 保持原真相与授权 |
| Producer / Consumer | 原 Session/Turn 仓储与只读历史生产投影，原 Agent 页面消费；反问帧仅用于重现问题，真正恢复仍经原服务与 SDK 校验 |
| Existing reuse | 原归属/Project、TurnInput、HITL、预算、历史、事件投影、trace、源受控回链；无新长期状态 |
| E2E evidence | SC01～SC08，下表区分自动化与真实环境；旧 G/T/QP/RA 不关闭 |

## 证据与取舍

这是静态可复现的流程断点，不是已建立的真实用户收益结论。[第五版](./IMPLEMENTATION_V5.md) 的采纳闭环继续保留，本轮不重复改采纳规则。旧计划优先真实试点，但用户明确授权继续第六版规划与实施，因此推进这一可确定验证的会话恢复路径；错误类别、跨执行比较、Dataset 口径、RAG/团队 Skill 的既有立项/试点门槛没有解除。

现有历史通过 SDK 消息分组、按顺序配对 trace，尚无可靠的活动消息与 turn ID 全量关联。本轮**不自动重放活动轮全文**，以免与历史正文重复；QUEUED/RUNNING 显示真实状态、阻止新提交，用户点击刷新读取最新状态和结果。已连接事件流原有游标续播保留。该范围不承诺进程崩溃后的 mid-turn 续跑；INTERRUPTED 仍诚实终态。

## 实施顺序

1. V6-0：F-014、Domain/Requirements 与既有 read-side 走廊说明。无新增导航、业务状态机、数据库、源 API 或 SDK 命令读取例外。
2. V6-1：新增兼容只读 continuation 接口；先校验本人及当前项目，再读最近提交轮次的目标和状态，不从消息/标题/工具名推断目标。普通最新轮 target 为 null 时明确保持普通对话，不回扫旧治理任务。
3. V6-2：仅 WAITING_INPUT 重现最新反问帧；帧缺失、输入投影损坏或身份不一致明确阻止继续，保留历史阅读。HITL 仍携带原 toolCallId/toolName，服务端恢复原 target/turnId/额度，不重置预算。读取不调用模型、不写 StateStore 或业务源。
4. V6-3：页面通过 sessionId URL 定位历史，刷新/切会话从服务器恢复；服务端范围优先于 URL 中的资产参数。加载时锁定提交，失败明确重试；快速切换/新会话忽略晚响应。新会话清除旧范围、待答与会话 URL。
5. V6-4：相关前后端回归、产品/架构护栏、完整前端测试/类型/构建和 PR CI；检查通过后合并，真实验收保留 PENDING。

## 验收

| ID | 场景与期望 |
|---|---|
| SC01 | 刷新或从侧栏重开治理会话，恢复最新持久化 target/purpose，明确追问仍携带该目标，不自动推理 |
| SC02 | 最新轮为普通问数时不回扫/猜测旧目标；无轮次的旧会话保持普通模式 |
| SC03 | WAITING_INPUT 显示原问题/选项，回答通过原恢复提交，保持同 turnId、任务和额度；伪造/过期回答仍拒绝 |
| SC04 | QUEUED/RUNNING 阻止重复新提问，显示状态并允许刷新；完成后可继续，INTERRUPTED 不冒充续跑 |
| SC05 | 无归属/跨项目/缺登录/身份不一致在读取前拒绝；continuation 不泄露载荷、私有提示或密钥 |
| SC06 | 损坏 payload、缺反问帧、读取失败显式阻止继续，不降为普通任务；历史仍可读/可重试 |
| SC07 | A/B 快速切换、新会话、卸载后忽略旧响应；不串对象、澄清或 trace，URL 来源参数不能覆盖服务端任务 |
| SC08 | 原事实卡、源回链、普通查询、取消与当前连接续播不回归；真实权限撤回/项目切换/模型回答另行验收 |

成功信号：实际用户重新打开会话后能辨认范围，并完成一次有效追问或原反问应答。当前真实基线 unknown，不承诺耗时、准确率和恢复率；观察须记录部署/账号/项目/模型/Skill/turn 和源审计。工程替身不能证明真实模型或生产可用性。
