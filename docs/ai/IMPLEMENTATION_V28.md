# Agent V28 — 模型结构变更解释与映射检查清单

日期：2026-10-09。基线 main 5b3a1716（V27 PR #441 已合并）。产品合同：[F-037](../product/features/F-037-agent-model-structure-review.md)，保持 IMPLEMENTING。

## 用户路径与真相

User：模型维护者及发布前复核人员。Problem：已保存结构、发布快照及当前来源映射分散，人工复核缺少统一检查清单。Capability：原版本页中的只读比较与显式 AI 说明。Journey：进入模型版本页 → 选择精确发布基准 → 准备服务端结构比较 → 查看差异/当前映射检查项/覆盖缺口 → AI 入口准备问题并明确发送 → 返回同一版本或原来源映射页人工核对。Outcome：理解受支持的结构变化及待检查项，不判定完整影响、源字段存在性、类型兼容或允许发布。

Truth Owner：Modeling 的已保存结构、不可变 ModelVersion 与当前来源映射；Security 的真实用户/项目授权；Agent 原 turn/StateStore 的执行和消息。Producer：ModelStructureReviewQueryApi；Consumer：原版本页及 Agent 原治理证据。复用原模型锁、StructureFingerprint、精确版本/映射仓储、授权恢复、工具预算、HITL、事实核验和官方历史。没有新模块、一级导航、表、状态机或第二份业务真相。

## 实现与限制

- 选择固定字符串 modelId、baselineVersionNo 和服务端 definition；其他目标互斥，URL/continuation/同轮预算恢复严格校验。无参数 get_model_structure_review_evidence 不能更换比较对象。普通对话不可调用；只允许原日期/反问/核验/只读 Skill 辅助能力。
- 源域先检查 Model READ 和项目，复用 getForUpdate 的原模型锁读取保存结构及当前映射。版本只按所选 versionNo 读取不可变快照；缺失/损坏/错配不回退。definition 包含完整保存结构指纹、版本行身份/原始快照摘要和当前映射摘要；包括未投影表达式等输入的变化也要求重新准备。
- 白名单比较表名/方言、字段名称/类型/长度/小数位/可空/顺序、主键、索引名称/唯一性/类型/字段、分区类型/字段。字段以不区分大小写的名称对齐；重命名按删除/新增，不推断身份。默认值/表达式/表属性/描述/标准语义/关系未比较，未保存编辑未读取。
- 当前映射 SQL 按 project/model、id ASC、LIMIT 101 FOR UPDATE；超过 100 拒绝，不读取无界列表后截断。每侧结构最多 100 字段/20 索引，原始及当前结构编码最多 262144 字符；结构仓储仍为原实现，没有数据库侧字段限量承诺。结果最多 24000 字符，超限或任一输入故障整次失败，不将缺证据解释为无差异。
- 当前映射只给出目标字段、映射是否存在、是否有转换及固定人工检查原因，包含未映射保存字段、遗留目标、变更目标和转换表达式复核。没有历史映射快照，不判断映射何时改变。源库表列、连接、原始表达式/SQL、操作者及凭据不进入输出；未访问外部源目录或数据。
- Agent 在同一用户/项目下预读，校验源返回的项目/对象/版本/指纹/容量，保留不可用/无权。关键值复用 verify_governance_facts，证据回链固定版本。交付前再恢复授权并核对 definition；失败时替换最终说明、去掉旧事实/证据卡片，并写回同一官方历史消息。内部交付检查不成为模型工具或增加模型工具预算。
- 版本页准备动作只读；AI 入口只导航并准备问题，不自动发送。项目/模型/版本/权限变化及新准备立即隔离旧入口，迟到响应不恢复。精确回链固定 tab=version/reviewVersion；指定版本无效显示重新选择，不替换当前版本。原保存、发布、回滚和来源映射编辑入口继续由原流程处理。
