## 事实归属与兼容范围

用户仍沿用现有接入、开发、治理、发布和消费旅程。Datasource、Workflow、Job、Modeling、MDM 等现有 owner 保有事实；Boot 只做装配，页面只做草稿与投影。没有新增一级导航、业务模块或业务状态。

执行容量、终态保留、取消确认和重启范围见 [运行与迁移契约](runtime-and-migration-contracts.md)。本地执行器支持单活动 JVM；不宣称多实例幂等认领或自动恢复未知副作用。新增日志保存的是终态结果，运行中崩溃仍由既有协调 owner 判断，不能伪造成功。

数据库支持当前 main 的合并基线及后续增量。历史合并前版本需要专门升级方案；此 PR 不自动 repair 旧历史，也不修改既有 SQL 基线。Java 8 / Boot 2 历史制品保持独立。

## 验收记录

- 本地边界检查覆盖 77 个 Reactor 条目；后端模块图无环、跨域持久化与公共契约检查通过。
- 前端跨域页面依赖收口后保留 1 条明确声明的现有走廊；迁移检查验证 30 份固定基线。
- Modeling 172 项、Job 30 项测试通过，包含新增纯计划、容量、持久幂等、日志失败和项目隔离场景。
- 各后端模块分段验证并修复当前契约与测试夹具失配。完整无过滤测试由 Linux CI 执行；本地 Windows JVM 无法建立 NIO 回环连接，HTTP mock 相关测试不能作为本地通过证据。
- Agent 取消句柄与 RUNNING 认领原子登记；推理初始化期间取消会释放迟到句柄，迟到完成回调不覆盖取消事实。新增确定性阻塞初始化回归测试。
- 新增 Boot 装配、插件最小 classpath、Workflow HTTP schema、UI 产物漂移、Home 部分不可用和迟到响应场景测试。
- 默认应用完整迁移 smoke 由 CI 的隔离 MySQL 执行。本地常驻预览锁定 Boot JAR，发行验证使用干净 CI checkout。

最终验收以 PR 同一提交的 Architecture gate、产品治理及现有框架检查结果为准。不能用测试过滤、放宽基线或修改历史 SQL 绕过失败。
