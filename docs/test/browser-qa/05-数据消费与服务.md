## 交互与共性问题
- **反馈缺失成通病**：保存草稿、保存大屏、删除大屏、点"添加图表"、点"线上预览"、点"添加规则"——六处操作成功/失败都无 toast 或状态变化；而 Key 启停、Key 停用等有 toast，同一分区反馈标准不统一。
- **空数据即死角**：本分区强依赖"已发布 Dataset / 已上线 Data Service"，无数据时目录、详情、调试、预览全线停摆且缺少引导文案（仅消费目录和调试下拉有基础空态）。
- **时间口径分裂**：分析展示（仪表盘/大屏）列表用 UTC，API 服务（调用方）用本地时间，同分区两套标准。
- **会话稳定性**：多分区并行共用 root 账号导致频繁互踢（后端 idleTimeout 默认 30min），产品层面对 401 中断没有任何草稿保护，长表单操作风险高。
