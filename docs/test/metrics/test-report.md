> 配套交付：`docs/test/metrics/issues.md`（issue 清单 M-1 ~ M-9，本文引用编号）

## 一、验收结论

指标中心**页面骨架与主干读路径可用**：列表统计、筛选、详情六区域、版本机制、停用/启用/删除流程、标签管理、血缘图谱（指标类依赖）均实测通过。

但发现 **2 个 P1 级功能阻断**：

1. **中文命名的指标无法可靠创建**（M-1）：编码自动生成只提取拉丁字母前缀（"QA测试原子指标" → `qa`），同前缀的第二个指标必然因编码冲突失败，纯中文名直接无法生成编码。
2. **创建失败完全无感知**（M-2）：接口返回明确业务错误（如 44002「指标编码已存在：qa」），前端吞掉错误不展示——点击创建后弹窗关闭、无 toast、无字段错误、列表不变，用户完全无法感知失败原因。复合指标创建因此 100% 静默失败（实测两次）。

另有血缘图谱不渲染模型依赖（M-3）、影响分析无法得出结论（M-4）两个 P2，以及 4 个 P3/观察项。**综合判断：指标中心的"建"能力（新建复合/派生指标）当前不具备可验收条件。**
