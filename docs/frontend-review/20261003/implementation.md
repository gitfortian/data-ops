# 全站前端升级实施与验收记录

分支：`codex/commercial-ui-clean-main`。基线：GitHub main `48594820`。本地 main `dcf214be` 中夹带的后端、迁移与测试修改未迁入本 PR；原工作区保持可恢复。

用户是数据工程、治理、分析与平台管理人员。当前问题是宽表、筛选密度、弱对比文字、窄屏导航与状态反馈影响定位对象和继续操作。能力目标是改善现有页面的可读性、响应式和操作反馈。

用户旅程：选择工作空间 → 找到对象 → 查看来源、状态与版本 → 进入已有允许操作 → 返回列表。期望结果是常用信息优先、完整字段可展开、窄屏保留导航与编辑入口。各既有领域继续拥有状态、授权、版本和运行事实；后端是 Producer，页面是 Consumer。复用 SiteLayout、权限过滤导航、Yak 组件、既有表格、目录与编辑器。
