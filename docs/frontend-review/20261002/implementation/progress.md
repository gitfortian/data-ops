# 商业化页面升级实施记录

分支：`codex/commercial-ui-upgrade`；基线：`545544c9`。范围为现有全站页面，按审核方案顺序实施，AI 助手模块排除。

## 产品边界

- User：数据工程、治理、分析与平台管理人员。
- Problem：页面层级、宽表、留白与窄屏布局影响对象定位及下一步操作。
- Capability：提升现有能力的可读性、响应式与操作反馈。
- Journey：当前空间 → 找到对象 → 查看事实与版本 → 进入现有允许操作 → 返回列表。
- Expected Outcome：常用信息优先，完整信息可展开，窄屏可导航和阅读。
- Truth Owner：各现有领域继续拥有状态、版本、授权与运行事实。
- Producer / Consumer：后端契约提供事实，前端只组织展示；无新增业务状态和 API。
- Reuse：SiteLayout、Yak 组件、SecurityQueryTable、既有目录、筛选与编辑器。
- E2E Evidence：浏览器截图与任务复验记录；未执行发布、运行、授权或删除操作。

## 验证记录

- 资产目录 390px：内容滚动宽度与容器一致；原审核宽度为 944px。
- 手机导航可以展开关闭；资产卡片可进入详情。
- 桌面复验发现旧开发服务尚未生成新响应式工具样式，正在独立预览服务重新构建后复验。
- 类型检查基线已有 180 条诊断；中间对比新增 0 条。最终结果以 `typecheck-comparison.json` 为准。
- 全站全部数据状态、权限角色、发布/执行流程尚未验收，不宣称已消除所有问题。
